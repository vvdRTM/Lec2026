## 1. Таблица как список строк

Обычный список хранит последовательность элементов. Элементом списка может быть другой список. Так получается **вложенный список**.

```python
measurements = [
    [18, 20, 19],
    [21, 17, 22],
]
```

Внешний список содержит два элемента. Каждый из них — список из трёх чисел. Если считать внутренние списки строками, перед нами таблица из двух строк и трёх столбцов.

| Строка / столбец | 0 | 1 | 2 |
|---|---:|---:|---:|
| 0 | 18 | 20 | 19 |
| 1 | 21 | 17 | 22 |

В примере строка соответствует моменту измерения, а столбец — датчику. Это смысловое соглашение программы: сами списки не знают, что обозначают числа.

### 1.1. Что означает слово «матрица»

Прямоугольную таблицу чисел часто называют матрицей. В этой лекции под матрицей понимаем список строк одинаковой длины. Специальные библиотеки для работы с матрицами пока не требуются.

Слово «строка» здесь имеет два значения. Строка таблицы — внутренний список. Текстовая строка типа `str` — последовательность символов. В выражении «прочитать строку файла и получить строку таблицы» сначала речь идёт о тексте, затем о списке чисел.

### 1.2. Внешний и внутренний уровни

```python
print(len(measurements))     # 2
print(measurements[0])       # [18, 20, 19]
print(len(measurements[0]))  # 3
```

Первый вызов `len()` считает строки таблицы. Второй считает элементы одной строки, то есть столбцы. Один и тот же `len()` отвечает на разные вопросы в зависимости от переданного объекта.

## 2. Два индекса для одной ячейки

К ячейке обращаются в два шага:

```python
matrix = [[18, 20, 19], [21, 17, 22]]

print(matrix[1])     # [21, 17, 22]
print(matrix[1][2])  # 22
```

`matrix[1]` получает вторую строку. Следующее `[2]` получает третий элемент этой строки. Поэтому первый индекс задаёт строку, второй — столбец.

```text
matrix[row_index][column_index]
```

Индексы начинаются с нуля. Для таблицы 2×3 допустимы индексы строк 0 и 1, индексы столбцов 0, 1 и 2.

### 2.1. Индекс и порядковый номер

Человек может сказать «вторая строка, третий столбец». В коде этому соответствуют индексы `[1][2]`.

Если вывод предназначен человеку, порядковый номер удобно вычислить как `index + 1`. Но для обращения к списку прибавлять единицу не нужно.

### 2.2. Изменение ячейки

```python
matrix = [[18, 20, 19], [21, 17, 22]]
matrix[0][1] = 25
print(matrix)  # [[18, 25, 19], [21, 17, 22]]
```

Внешний список по-прежнему содержит две строки. Изменился один элемент первого внутреннего списка.

### 2.3. Ошибки границ

`matrix[2]` для этой таблицы вызовет `IndexError`: третьей строки нет. `matrix[0][3]` тоже вызовет `IndexError`, но уже на внутреннем уровне: в первой строке нет четвёртого элемента.

Чтобы найти причину, нужно определить, какое из двух обращений вышло за границу.

## 3. Размеры и прямоугольность

Для непустой прямоугольной таблицы размеры можно получить так:

```python
matrix = [[18, 20, 19], [21, 17, 22]]
row_count = len(matrix)
column_count = len(matrix[0])

print(row_count, column_count)  # 2 3
```

Число столбцов первой строки подходит для всей таблицы, только если все строки имеют одинаковую длину.

### 3.1. Вложенный список не обязан быть прямоугольным

```python
rows = [[1, 2], [3], [4, 5, 6]]
```

Это допустимый Python-объект. Но он не соответствует нашему договору о прямоугольной таблице. Попытка обработать все строки по длине первой может пропустить данные или вызвать ошибку.

Поэтому программа должна либо получать уже проверенную таблицу, либо проверять её форму на входе.

### 3.2. Пустая таблица

```python
matrix = []
print(len(matrix))  # 0
```

У такой таблицы нет первой строки. Команда `matrix[0]` недопустима. Если пустой вход разрешён, его обрабатывают до определения столбцов:

```python
if not matrix:
    print("Таблица пуста")
else:
    print(len(matrix), len(matrix[0]))
```

`[]` и `[[]]` различаются. В первом случае нет строк, во втором есть одна строка без элементов. Для прямоугольной таблицы с положительными размерами оба случая могут быть недопустимыми, но причины разные.

## 4. Вложенные циклы

Чтобы обработать каждый элемент, сначала выбираем строку, затем перебираем её значения:

```python
matrix = [[18, 20, 19], [21, 17, 22]]

for row in matrix:
    for value in row:
        print(value)
```

Внешний цикл получает список `[18, 20, 19]`. Внутренний цикл полностью проходит его: 18, 20, 19. Затем внешний цикл получает следующую строку, и внутренний цикл выполняется заново: 21, 17, 22.

### 4.1. Порядок выполнения

| Шаг | Текущая строка | Текущее значение |
|---:|---|---:|
| 1 | `[18, 20, 19]` | 18 |
| 2 | `[18, 20, 19]` | 20 |
| 3 | `[18, 20, 19]` | 19 |
| 4 | `[21, 17, 22]` | 21 |
| 5 | `[21, 17, 22]` | 17 |
| 6 | `[21, 17, 22]` | 22 |

Таблица 2×3 содержит шесть ячеек, поэтому самая внутренняя команда выполняется шесть раз.

### 4.2. Отступы определяют уровень действия

```python
for row in matrix:
    print("Начало строки")
    for value in row:
        print(value)
    print("Конец строки")
```

«Начало строки» и «Конец строки» выводятся два раза. Числовой элемент выводится шесть раз. Перемещение команды на один уровень отступа меняет количество её выполнений.

## 5. Обход по индексам и через enumerate

Если требуется знать положение ячейки, нужны индексы:

```python
matrix = [[18, 20, 19], [21, 17, 22]]

for row_index, row in enumerate(matrix):
    for column_index, value in enumerate(row):
        print(row_index, column_index, value)
```

Начало вывода:

```text
0 0 18
0 1 20
0 2 19
1 0 21
```

Можно использовать и `range()`:

```python
for row_index in range(len(matrix)):
    for column_index in range(len(matrix[row_index])):
        print(matrix[row_index][column_index])
```

### 5.1. Как выбрать способ обхода

Если нужен только элемент, прямой цикл по значениям проще. Если нужно сохранить координаты или заменить элемент, используйте индексы. `enumerate()` позволяет получать значение и индекс одновременно.

Название `row` обычно означает сам список строки. Название `row_index` означает его номер. Если смешать эти роли, легко написать `matrix[row]`, хотя `row` является списком, а не целым индексом.

## 6. Обработка строк и столбцов

Строка уже является отдельным внутренним списком, а столбец обычно приходится собирать из разных строк.

```python
matrix = [[18, 20, 19], [21, 17, 22]]

first_row = matrix[0]
second_column = []
for row in matrix:
    second_column.append(row[1])

print(first_row)      # [18, 20, 19]
print(second_column)  # [20, 17]
```

Чтобы получить второй столбец, из каждой строки берём элемент с индексом 1. У всех выбранных ячеек одинаковый индекс столбца, а индекс строки меняется.

### 6.1. Вычисление показателя строки

К строке таблицы применимы знакомые операции списка:

```python
matrix = [[18, 20, 19], [21, 17, 22]]

for index, row in enumerate(matrix):
    print(f"Измерение {index + 1}: максимум {max(row)}")
```

Результаты — максимумы 20 и 22. Для `max()` строка должна быть непустой.

Для суммирования используется тот же принцип: сумма строки — сумма элементов одного внутреннего списка. Сумма столбца — сумма значений с одинаковым индексом столбца из всех строк.

### 6.2. Где создавать накопитель

Если нужен один общий результат для таблицы, накопитель создают перед обоими циклами. Если нужен отдельный результат для каждой строки, его создают внутри внешнего цикла, но перед внутренним.

```python
matrix = [[18, 20, 19], [21, 17, 22]]

for row_index, row in enumerate(matrix):
    above_limit = 0
    for value in row:
        if value > 19:
            above_limit += 1
    print(row_index, above_limit)
```

Для первой строки подходит только 20, для второй — 21 и 22. Результаты: `0 1` и `1 2`.

### 6.3. Отдельный обход каждого столбца

Для получения одного показателя на столбец меняется порядок циклов: внешний выбирает столбец, внутренний проходит строки.

```python
matrix = [[18, 20, 19], [21, 17, 22]]

for column_index in range(len(matrix[0])):
    maximum = matrix[0][column_index]
    for row in matrix:
        if row[column_index] > maximum:
            maximum = row[column_index]
    print(f"Датчик {column_index + 1}: максимум {maximum}")
```

Для столбца 0 сравниваются 18 и 21, максимум 21. Для столбца 1 сравниваются 20 и 17, максимум 20. Для столбца 2 сравниваются 19 и 22, максимум 22.

| Показатель | Что закреплено | Что меняется |
|---|---|---|
| Для одной строки | Индекс строки | Индекс столбца |
| Для одного столбца | Индекс столбца | Индекс строки |
| Для всей таблицы | Ничего | Оба индекса |

Точно так же строится накопление суммы. Для первой строки получается `18 + 20 + 19 = 57`, для второй `21 + 17 + 22 = 60`. По столбцам: `18 + 21 = 39`, `20 + 17 = 37`, `19 + 22 = 41`.

Общая сумма совпадает при обоих способах: `57 + 60 = 39 + 37 + 41 = 117`. Это полезная независимая проверка обхода. Но одно совпадение общей суммы не доказывает правильность каждого отдельного элемента результата, поэтому проверяйте и сами показатели.

## 7. Почему таблица 2×3 полезнее первого примера 3×3

В квадратной таблице количество строк равно количеству столбцов. Если случайно использовать `len(matrix)` в обоих циклах, ошибка может остаться незаметной.

В прямоугольной таблице 2×3:

- `len(matrix)` равно 2;
- `len(matrix[0])` равно 3;
- строк две, но в каждой три элемента.

Если внутренний цикл выполнить только два раза, последний столбец будет пропущен. В таблице 3×2 та же ошибка может привести к обращению за границу.

### 7.1. Полезные формы для проверки

| Форма | Что помогает проверить |
|---|---|
| 2×3 | Разные количества строк и столбцов |
| 3×2 | Обратное соотношение размеров |
| 1×4 | Работа с одной строкой |
| 4×1 | Работа с одним столбцом |
| 1×1 | Единственный элемент |
| Пустая таблица | Отсутствие первой строки |

Проверять нужно не только значения ячеек, но и форму результата. Например, один показатель на столбец должен дать три элемента для таблицы с тремя столбцами.

## 8. Создание независимых строк

Таблицу можно постепенно построить обычными циклами:

```python
row_count = 2
column_count = 3
matrix = []

for _ in range(row_count):
    row = []
    for _ in range(column_count):
        row.append(0)
    matrix.append(row)

matrix[0][1] = 7
print(matrix)  # [[0, 7, 0], [0, 0, 0]]
```

На каждом шаге внешнего цикла создаётся новый внутренний список. Поэтому изменение первой строки не затрагивает вторую.

Сокращённая запись:

```python
matrix = [[0] * column_count for _ in range(row_count)]
```

Внутреннее выражение `[0] * column_count` выполняется отдельно для каждой строки.

### 8.1. Ошибка повторения одного списка

```python
matrix = [[0] * 3] * 2
matrix[0][1] = 7
print(matrix)  # [[0, 7, 0], [0, 7, 0]]
```

Сначала создан один список `[0, 0, 0]`. Умножение внешнего списка повторило ссылку на него. Внешних элементов два, но оба ведут к одному внутреннему объекту.

Это не «автоматическое изменение двух ячеек». Изменяется одна ячейка одного списка, который показывается в двух местах.

### 8.2. Почему [0] * columns здесь допустимо

Ноль является неизменяемым числом. При команде `row[1] = 7` заменяется элемент списка, а не изменяется объект нуля. Опасность появляется при повторении ссылок на изменяемые объекты: списки, словари и подобные контейнеры.

## 9. Копирование таблицы

`matrix.copy()` создаёт отдельный внешний список, но сохраняет общие внутренние строки:

```python
original = [[1, 2], [3, 4]]
copy = original.copy()
copy[0][0] = 99

print(original)  # [[99, 2], [3, 4]]
```

Для таблицы чисел, где нужно независимо менять ячейки и строки, достаточно скопировать каждую строку:

```python
original = [[1, 2], [3, 4]]
copy = [row.copy() for row in original]
copy[0][0] = 99

print(original)  # [[1, 2], [3, 4]]
print(copy)      # [[99, 2], [3, 4]]
```

### 9.1. Что именно стало независимым

| Способ | Новый внешний список | Новые списки строк |
|---|---|---|
| `copy = original` | Нет | Нет |
| `copy = original.copy()` | Да | Нет |
| `[row.copy() for row in original]` | Да | Да |

Если внутри ячеек тоже находятся изменяемые объекты, такой двухуровневой копии может оказаться недостаточно. Но для таблицы целых чисел это соответствует рассматриваемой задаче независимости.

## 10. Преобразование на месте и новый результат

Намеренное изменение исходной таблицы:

```python
matrix = [[18, 20], [21, 17]]

for row_index, row in enumerate(matrix):
    for column_index, value in enumerate(row):
        matrix[row_index][column_index] = value + 1

print(matrix)  # [[19, 21], [22, 18]]
```

Если исходные данные нужно сохранить, строят новые строки:

```python
def shifted_table(matrix, offset):
    result = []
    for row in matrix:
        new_row = []
        for value in row:
            new_row.append(value + offset)
        result.append(new_row)
    return result


original = [[18, 20], [21, 17]]
changed = shifted_table(original, 1)
print(original)  # [[18, 20], [21, 17]]
print(changed)   # [[19, 21], [22, 18]]
```

На каждой итерации внешнего цикла `new_row` создаётся заново. Если создать её один раз перед циклом, результат перестанет состоять из независимых строк.

Для пустого списка эта функция вернёт `[]`: внешний цикл не выполнится.

<a id="section-11"></a>

## 11. Индексы и геометрия таблицы

Условия можно применять не только к значению ячейки, но и к её положению.

Для квадратной таблицы:

| Условие | Положение |
|---|---|
| `row_index == column_index` | Главная диагональ |
| `row_index < column_index` | Выше главной диагонали |
| `row_index > column_index` | Ниже главной диагонали |

Главная диагональ идёт от левого верхнего угла к правому нижнему. Для размера 3 это ячейки `(0, 0)`, `(1, 1)`, `(2, 2)`.

### 11.1. Как увидеть смысл сравнения

В ячейке `(0, 2)` индекс строки меньше индекса столбца: ячейка находится правее диагонали в верхней части. В ячейке `(2, 0)` индекс строки больше: ячейка расположена ниже диагонали.

Пример другого рисунка — чередование меток:

```python
board = []
for row_index in range(3):
    row = []
    for column_index in range(4):
        if (row_index + column_index) % 2 == 0:
            row.append("A")
        else:
            row.append("B")
    board.append(row)

for row in board:
    print(*row)
```

Результат:

```text
A B A B
B A B A
A B A B
```

Чётность суммы индексов меняется при переходе на одну ячейку вправо или вниз.

<a id="section-12"></a>

## 12. Ввод и вывод таблицы

Человек обычно вводит одну строку таблицы одной текстовой строкой. Программа должна выполнить два преобразования: разделить текст на части, затем каждую часть превратить в число.

```python
text = "18 20 19"
parts = text.split()
row = [int(part) for part in parts]

print(parts)  # ['18', '20', '19']
print(row)    # [18, 20, 19]
```

Если ожидается три столбца, после преобразования проверяют `len(row) == 3`. Корректные числа сами по себе не гарантируют корректную длину строки.

### 12.1. Вывод без скобок

```python
row = [18, 20, 19]
print(row)   # [18, 20, 19]
print(*row)  # 18 20 19
```

Звёздочка перед `row` распаковывает список в отдельные аргументы функции. Второй вызов работает как `print(18, 20, 19)`.

Для получения текстовой строки без немедленного вывода:

```python
row = [18, 20, 19]
parts = [str(value) for value in row]
line = " ".join(parts)
print(line)  # 18 20 19
```

`join()` требует строки, поэтому сначала используется `str(value)`. Полученный `line` можно записать в файл.

<a id="section-13"></a>

## 13. Зачем программе файл

Переменные хранят данные работающего процесса. После завершения обычной программы созданный в памяти список сам по себе не сохраняется для следующего запуска.

Файл позволяет хранить данные на диске: заметки, настройки, таблицу измерений или готовый результат.

В работе с файлом различаются:

- **путь**: где находится файл;
- **содержимое**: какие данные записаны;
- **формат**: как следует понимать содержимое;
- **кодировка**: как текстовые символы представлены байтами.

Файл с расширением `.txt` не обязательно содержит правильные данные. Расширение подсказывает назначение человеку, но не доказывает соответствие формату.

### 13.1. Текст и данные в памяти

```text
18 20 19
21 17 22
```

В файле это символы цифр, пробелов и переводов строк. После чтения и преобразования программа может получить `[[18, 20, 19], [21, 17, 22]]`. Файл не превращается в список автоматически.

<a id="section-14"></a>

## 14. Пути и текущая рабочая папка

Абсолютный путь задаёт местоположение целиком. Относительный путь считается от **текущей рабочей папки процесса**.

```python
from pathlib import Path

print(Path.cwd())
```

Вызов показывает папку, от которой будут отсчитываться относительные пути. Она зависит от способа запуска и может не совпадать с папкой `.py`-файла.

### 14.1. Path

```python
from pathlib import Path

folder = Path("data")
source = folder / "measurements.txt"
print(source)
```

Оператор `/` для объектов `Path` соединяет части пути. В этом выражении он не делит числа.

### 14.2. Файл рядом со скриптом

В сохранённом Python-файле:

```python
from pathlib import Path

folder = Path(__file__).resolve().parent
source = folder / "measurements.txt"
```

`__file__` содержит путь файла программы; `resolve()` получает абсолютное представление пути, `parent` — родительскую папку. В интерактивной оболочке и некоторых блокнотах `__file__` обычно не определено.

### 14.3. Запись пути не создаёт файл

`Path("data") / "notes.txt"` только описывает путь. Если папки `data` нет, обычное открытие вложенного файла для записи не создаст её автоматически.

Убедитесь, что путь ведёт к нужному месту, до записи. Особенно важно различать файл исходных данных и файл результата.

<a id="section-15"></a>

## 15. Кодировка UTF-8

На диске текст хранится как последовательность байтов. **Кодировка** задаёт соответствие между символами и байтами.

При чтении нужно использовать кодировку, в которой файл был сохранён. В примерах курса явно указываем `encoding="utf-8"`.

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    text = file.read()
```

Без явной кодировки результат может зависеть от настроек среды. Неправильная кодировка иногда вызывает `UnicodeDecodeError`, а иногда даёт нечитаемый текст без исключения.

### 15.1. Длина строки и размер файла

`len(text)` считает элементы Python-строки, а размер файла измеряется байтами. Они не обязаны совпадать: русская буква в UTF-8 обычно занимает больше одного байта.

Не нужно удалять или игнорировать непонятные байты, чтобы «ошибка исчезла». Сначала установите настоящую кодировку файла и ожидаемый формат.

<a id="section-16"></a>

## 16. open, режим и with

Функция `open()` открывает файл и возвращает файловый объект. Через него программа читает и записывает данные.

| Режим | Назначение | Если файла нет | Если файл существует |
|---|---|---|---|
| `r` | Чтение | Ошибка | Содержимое сохраняется |
| `w` | Новая запись | Файл создаётся | Прежнее содержимое обнуляется при открытии |
| `a` | Добавление в конец | Файл создаётся | Прежнее содержимое сохраняется |

### 16.1. Почему нужен with

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(text)
```

После выхода из блока файловый объект закрывается. Это происходит и при обычном завершении блока, и при исключении внутри него. Если само открытие не удалось, файловый объект не был получен и тело блока не выполняется.

Имя `file` — обычное имя переменной. Можно назвать его `source_file`, чтобы показать назначение.

### 16.2. Закрытый файл и прочитанное значение

После блока нельзя продолжить чтение через закрытый файловый объект. Но `text` уже содержит обычную строку в памяти, поэтому её можно использовать дальше.

`with` организует освобождение ресурса. Он не исправляет ошибки данных и не означает, что запись стала защищённой от любых сбоев.

<a id="section-17"></a>

## 17. Чтение файла целиком и по строкам

### 17.1. read

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    text = file.read()
```

`read()` без аргумента читает всё оставшееся содержимое и возвращает одну строку. Это удобно для небольшого текста.

### 17.2. readline

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    first = file.readline()
    second = file.readline()
```

Каждый вызов читает следующую строку. Перевод строки, если он присутствует, обычно входит в результат.

При достижении конца файла `readline()` возвращает `""`. Пустая строка внутри файла обычно читается как `"\n"`, поэтому эти случаи различаются.

### 17.3. readlines

`readlines()` возвращает список оставшихся строк. Это не список чисел и не автоматически готовая таблица.

Аргумент `readlines(hint)` не задаёт номер строки. Это ориентир объёма чтения, который не следует использовать для выбора «третьей строки».

### 17.4. Положение чтения

Файл можно представить как текст с указателем текущей позиции. После чтения указатель сдвигается:

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    first_part = file.read()
    second_part = file.read()

print(repr(second_part))  # ''
```

Второй вызов не перечитывает всё сначала. Для отдельного нового прохода можно заново открыть файл. При больших файлах обычно выбирают построчную обработку.

<a id="section-18"></a>

## 18. Построчное чтение и переводы строк

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    for line_number, line in enumerate(file, start=1):
        print(line_number, line.rstrip("\n"))
```

`enumerate(..., start=1)` начинает нумерацию с единицы. Это удобно для сообщений человеку: первая строка файла имеет номер 1, даже если индексы списков начинаются с нуля.

### 18.1. Откуда берутся пустые строки при выводе

Если `line` уже заканчивается `\n`, а `print(line)` добавляет ещё один перевод строки, между строками появятся дополнительные промежутки.

Два обычных решения:

```python
print(line, end="")
```

или:

```python
print(line.rstrip("\n"))
```

Первое сохраняет прочитанное окончание строки, второе убирает его перед обычным `print()`.

### 18.2. strip может удалить полезные данные

`line.strip()` удаляет не только перевод строки, но и пробельные символы по краям. Это удобно, если формат разрешает такие изменения. Но при работе с текстом, где отступы важны, такое действие потеряет информацию.

Правило обработки пробелов должно следовать формату, а не привычке всегда вызывать `strip()`.

<a id="section-19"></a>

## 19. Запись и добавление текста

Следующий пример создаёт или перезаписывает учебный файл `demo_notes.txt` в текущей рабочей папке:

```python
with open("demo_notes.txt", "w", encoding="utf-8") as file:
    file.write("Состояние: готово\n")
    file.write("Соединение: установлено\n")
```

`write()` не добавляет перевод строки автоматически. Поэтому `\n` указывается явно.

При добавлении записи:

```python
with open("demo_notes.txt", "a", encoding="utf-8") as file:
    file.write("Проверка завершена\n")
```

Если прежний файл не заканчивается переводом строки, добавляемый текст продолжится в той же строке. Это нужно учитывать при выборе формата журнала.

### 19.1. Опасность преждевременного открытия в режиме w

Содержимое существующего файла очищается уже при успешном открытии в `w`, до первой команды `write()`. Даже если позже программа обнаружит неправильные данные, старое содержимое уже потеряно.

Поэтому результат открывают для записи после успешного чтения, проверки и вычисления. Исходные данные читают в `r` и не открывают для записи в ходе обычной обработки.

### 19.2. writelines

`writelines()` записывает последовательность строк, но не вставляет между ними переводы строк автоматически. Если нужны отдельные строки файла, окончания должны уже присутствовать в элементах или текст следует собрать через `join()`.

<a id="section-20"></a>

## 20. Формат данных как договор

Формат — правила, по которым текст превращается в данные. Например:

```text
18 20 19
21 17 22
```

Для этой демонстрации договоримся: каждая строка содержит ровно три целых показания, пустые строки не разрешены, требуется хотя бы одна строка.

Тогда текст `18 20` нарушает количество полей, `18 x 19` — правило целых чисел, а пустой файл — требование наличия данных.

### 20.1. Файл с заголовком

В другом формате первая строка может содержать количество строк и столбцов. Тогда алгоритм должен отдельно проверить:

1. Заголовок существует.
2. В заголовке ровно два поля.
3. Оба поля преобразуются в целые числа.
4. Оба размера положительны.
5. Количество строк данных соответствует заголовку.
6. Каждая строка данных имеет требуемую длину.
7. Каждая ячейка содержит допустимое число.
8. После ожидаемых данных нет лишних строк.

Два формата могут использовать одинаковые числа, но требовать разного чтения. Нельзя автоматически считать первую строку заголовком, если формат этого не предусматривает.

<a id="section-21"></a>

## 21. Что такое исключение

**Исключение** сообщает, что операция не смогла завершиться обычным способом.

```python
number = int("три")
```

Это допустимая по синтаксису команда, но строка не обозначает целое число. Возникает `ValueError`.

Если исключение не обработано, выполнение текущего пути прерывается и Python показывает сообщение об ошибке. Начинать чтение сообщения полезно с последней строки: там указаны тип и пояснение. Затем найдите имя файла и строку кода.

### 21.1. Ошибка выполнения и ошибка результата

```python
values = [2, 4]
average = sum(values) / 3
print(average)
```

Исключения нет, но среднее вычислено неверно: элементов два. Это логическая ошибка. `try/except` не доказывает правильность формулы и не заменяет проверку ожидаемого результата.

### 21.2. Ожидаемые внешние проблемы

Пользователь может ввести буквы, файл может отсутствовать, доступ может быть запрещён. Такие ситуации программа способна объяснить понятным сообщением и, когда это предусмотрено, предложить повторение.

Ошибку в собственном коде, например опечатку в имени, нельзя считать нормальным пользовательским вводом. Её нужно обнаружить и исправить.

<a id="section-22"></a>

## 22. try и except

```python
text = input("Целое число: ")

try:
    number = int(text)
except ValueError:
    print("Введено не целое число")
else:
    print(f"Получено: {number}")
```

`try` содержит операцию, которая может вызвать ожидаемую ошибку. `except ValueError` обрабатывает именно этот тип. `else` выполняется, если блок `try` завершился без исключения.

### 22.1. Два пути выполнения

| Ввод | Действие int | Следующая ветвь |
|---|---|---|
| `"12"` | Получено число 12 | `else` |
| `"abc"` | Возникает `ValueError` | `except ValueError` |

После возникновения исключения оставшиеся команды того же `try` не выполняются. Выполнение не возвращается автоматически к ошибочной строке.

### 22.2. Узкий блок try

Старайтесь помещать в `try` небольшой понятный участок. Если обернуть всё приложение одним обработчиком `ValueError`, станет трудно установить, какая именно операция оказалась неверной.

Операции в `else` выполняются вне защиты предшествующего `except`: исключение из самого `else` он не перехватывает.

<a id="section-23"></a>

## 23. Преобразование типа и проверка значения

`int()` проверяет возможность получить целое число, но не устанавливает правила задачи. Ноль и отрицательные числа преобразуются успешно, хотя могут быть недопустимым размером.

Пример ввода разрешённого уровня от 1 до 5:

```python
while True:
    text = input("Уровень от 1 до 5: ")
    try:
        level = int(text)
    except ValueError:
        print("Нужно целое число")
        continue

    if not 1 <= level <= 5:
        print("Уровень должен быть от 1 до 5")
        continue

    break

print(f"Выбран уровень {level}")
```

### 23.1. Разбор попыток

| Ввод | Преобразование | Проверка диапазона | Действие |
|---|---|---|---|
| `abc` | Ошибка | Не выполняется | Сообщение о типе |
| `0` | Успешно | Ложно | Сообщение о диапазоне |
| `7` | Успешно | Ложно | Сообщение о диапазоне |
| `3` | Успешно | Истинно | Выход из цикла |

`continue` начинает следующую попытку, `break` завершает цикл. После ошибочного преобразования программа не пытается использовать не полученное значение как корректный уровень.

<a id="section-24"></a>

## 24. raise и сообщения об ошибках формата

Некоторые нарушения Python не обнаруживает автоматически. Строка из двух целых чисел допустима как текст, но неверна, если требуются три значения.

Функция может сама сообщить о нарушении через `raise`:

```python
def parse_reading(line, line_number):
    parts = line.split()
    if len(parts) != 3:
        raise ValueError(
            f"Строка {line_number}: ожидалось 3 показания, получено {len(parts)}"
        )

    try:
        values = [int(part) for part in parts]
    except ValueError as error:
        raise ValueError(
            f"Строка {line_number}: каждое показание должно быть целым числом"
        ) from error

    return values


print(parse_reading("18 20 19", 1))  # [18, 20, 19]
```

### 24.1. Зачем передавать номер строки

Сообщение «Неверный файл» почти не помогает исправить данные. Сообщение «Строка 5: ожидалось 3 показания, получено 2» указывает место и причину.

`except ValueError as error` связывает объект исключения с именем. Запись `raise ... from error` сохраняет связь новой ошибки с исходной. Для начинающего главное — понять, что мы добавляем контекст, а не скрываем проблему.

### 24.2. Возврат и исключение

При правильной строке функция возвращает список чисел. При неправильной она не возвращает частичный список, а сообщает об ошибке. Вызывающий код выбирает, показать сообщение, прекратить обработку или запросить данные заново.

<a id="section-25"></a>

## 25. Типы исключений и порядок обработчиков

| Тип | Типичная причина |
|---|---|
| `ValueError` | Строка не преобразуется в число или нарушен заявленный формат |
| `FileNotFoundError` | Файл или часть пути отсутствует |
| `PermissionError` | Недостаточно разрешений на операцию |
| `OSError` | Другие ошибки файловой системы и ввода-вывода |
| `UnicodeDecodeError` | Байты нельзя прочитать выбранной кодировкой |
| `IndexError` | Индекс вне границ списка |
| `TypeError` | Операция не подходит типу объекта |

Некоторые исключения являются частными случаями других. Например, `FileNotFoundError` и `PermissionError` относятся к семейству `OSError`. `UnicodeDecodeError` относится к `UnicodeError`, а это семейство связано с `ValueError`.

Поэтому более конкретные обработчики ставят раньше общих:

```python
try:
    with open("notes.txt", "r", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("Файл не найден")
except UnicodeError:
    print("Проверьте кодировку UTF-8")
except OSError as error:
    print(f"Не удалось прочитать файл: {error}")
```

Если рядом будет обработчик `ValueError`, его нужно расположить после `UnicodeError`, чтобы ошибка декодирования не выглядела как ошибка числового формата.

### 25.1. Почему нельзя скрывать все ошибки

Пустой `except:` с `pass` может спрятать не только неверный ввод, но и ошибку программы, а также сигнал прерывания. В результате пользователь увидит отсутствие результата без объяснения.

Обрабатывайте ожидаемые типы, сохраняйте полезное сообщение и оставляйте возможность обнаружить ошибки самого алгоритма.

<a id="section-26"></a>

## 26. finally и закрытие ресурсов

`finally` выполняется при выходе из конструкции независимо от того, возникло ли исключение. Он нужен для завершающих действий.

```python
try:
    number = int("12")
except ValueError:
    print("Не число")
else:
    print(number)
finally:
    print("Попытка обработки завершена")
```

Последняя строка выводится и при успешном преобразовании, и при обработанной ошибке. `finally` выполняется также при обычном выходе через `return` или `break`. При принудительном завершении процесса или отключении питания на это рассчитывать нельзя.

### 26.1. with и finally решают разные вопросы

Для открытия обычного файла используйте `with`: он сам организует закрытие. Не нужно дополнительно вызывать `close()` в `finally`, если контекст уже управляет файлом.

`except` отвечает, как программа реагирует на ошибку. `finally` отвечает, какое завершающее действие должно произойти. `with` управляет ресурсом. Эти конструкции могут использоваться вместе, но не заменяют друг друга.

<a id="section-27"></a>

## 27. Общий пример: чтение показаний из файла

Соберём небольшую программу на другом формате, чем файл с заголовком размеров. В нашем примере каждая строка содержит ровно три целых показания, заголовка нет. Пустой файл и пустые строки запрещены.

Создайте рядом со скриптом файл `readings.txt` в UTF-8:

```text
18 20 19
21 17 22
```

Полный пример:

```python
from pathlib import Path


def parse_reading(line, line_number):
    parts = line.split()
    if len(parts) != 3:
        raise ValueError(f"Строка {line_number}: нужны три показания")
    try:
        return [int(part) for part in parts]
    except ValueError as error:
        raise ValueError(
            f"Строка {line_number}: показания должны быть целыми"
        ) from error


def load_readings(path):
    matrix = []
    with open(path, "r", encoding="utf-8") as file:
        for line_number, line in enumerate(file, start=1):
            matrix.append(parse_reading(line, line_number))
    if not matrix:
        raise ValueError("Файл не содержит показаний")
    return matrix


def describe_readings(matrix):
    row_count = len(matrix)
    column_count = len(matrix[0])
    maximum = max(value for row in matrix for value in row)
    return (
        f"Измерений: {row_count}\n"
        f"Датчиков: {column_count}\n"
        f"Наибольшее показание: {maximum}\n"
    )


def main():
    folder = Path(__file__).resolve().parent
    source = folder / "readings.txt"
    destination = folder / "readings_summary.txt"

    try:
        matrix = load_readings(source)
        summary = describe_readings(matrix)
    except FileNotFoundError:
        print("Не найден файл readings.txt")
        return
    except UnicodeError:
        print("Не удалось прочитать текст в UTF-8")
        return
    except ValueError as error:
        print(f"Неверные данные: {error}")
        return
    except OSError as error:
        print(f"Ошибка чтения: {error}")
        return

    try:
        with open(destination, "w", encoding="utf-8") as file:
            file.write(summary)
    except OSError as error:
        print(f"Не удалось сохранить результат: {error}")
        return

    print(summary, end="")


if __name__ == "__main__":
    main()
```

При успешном запуске файл результата и вывод содержат:

```text
Измерений: 2
Датчиков: 3
Наибольшее показание: 22
```

### 27.1. Разделение ответственности

| Функция | Что делает | Что возвращает |
|---|---|---|
| `parse_reading()` | Проверяет одну текстовую строку | Список из трёх целых чисел |
| `load_readings()` | Читает файл и проверяет строки | Проверенную таблицу |
| `describe_readings()` | Формирует описание | Готовую строку |
| `main()` | Организует работу и сообщения человеку | Содержательный результат не требуется |

Вычисляющая функция получает уже проверенную непустую таблицу. Поэтому внутри неё допустимы `matrix[0]` и поиск максимума. Этот договор должен быть понятен вызывающему коду.

### 27.2. Новая запись в поиске максимума

`max(value for row in matrix for value in row)` перебирает сначала строки, затем элементы. Это выражение-генератор: оно выдаёт значения по мере запроса, а не создаёт отдельный список всех ячеек.

Чтобы сначала увидеть привычный цикл, выражение можно заменить:

```python
maximum = matrix[0][0]
for row in matrix:
    for value in row:
        if value > maximum:
            maximum = value
```

Оба подхода предполагают наличие хотя бы одной ячейки. Числовой максимум не инициализируется нулём, который мог отсутствовать в данных.

<a id="section-28"></a>

## 28. Проверка до записи результата

В полном примере файл результата открывается только после завершения чтения и формирования сообщения. Если исходный файл не найден или данные некорректны, выполнение возвращается из `main()` раньше.

Следовательно, ошибка входных данных не приводит к очистке прежнего `readings_summary.txt`.

### 28.1. Последовательность обработки

```text
Получить путь
Прочитать входной файл
Проверить формат и значения
Вычислить результат
Сформировать текст
Открыть отдельный файл результата
Записать текст
```

Нельзя переносить открытие файла результата выше проверок только для удобства расположения кода.

### 28.2. Конец файла и пустая строка

Один перевод строки после последней строки данных нормален. Но дополнительная пустая строка — отдельная строка файла и должна оцениваться по правилам формата.

В построчном цикле:

- текст `"18 20 19\n"` даёт одну строку;
- текст `"18 20 19\n\n"` даёт строку данных и пустую строку;
- пустой файл не даёт ни одной итерации.

Если пустые строки запрещены, нельзя удалять их из списка перед проверкой: это скроет нарушение и может сдвинуть номера строк.

### 28.3. Предел этой защиты

Правильный порядок защищает старый результат от ошибок входа. Но если сбой произошёл уже во время записи в `w`, прежний файл мог быть очищен, а новый — записан частично. Отдельная обработка `OSError` покажет проблему, но сама по себе не восстановит данные. Способ уменьшить этот риск обсуждается в дополнительном разделе.

<a id="section-29"></a>

## 29. Как проверять программы с файлами

Проверки должны охватывать правильный ввод, ошибки формата и файловые проблемы. Для учебных экспериментов удобно использовать отдельную временную папку.

### 29.1. TemporaryDirectory

```python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    path = Path(directory) / "example.txt"
    path.write_text("Состояние: готово\n", encoding="utf-8")
    text = path.read_text(encoding="utf-8")
    assert text == "Состояние: готово\n"

print("Проверка завершена")
```

Файлы создаются в отдельном месте, а после выхода из контекста временная папка удаляется. Эти данные нужны только для проверки; не сохраняйте туда единственную копию важного результата.

### 29.2. Проверка ожидаемого исключения

Для функции `parse_reading()` из раздела 24:

```python
try:
    parse_reading("18 x 19", 4)
except ValueError as error:
    assert "4" in str(error)
else:
    assert False, "Некорректные данные остались незамеченными"
```

Если исключение не возникнет, `else` обнаружит неправильное поведение. Просто выполнить ошибочный вызов недостаточно: нужно проверить, что программа действительно отреагировала ожидаемым способом.

### 29.3. Набор файловых случаев

| Ситуация | Ожидаемая реакция |
|---|---|
| Две корректные строки по три числа | Проверенная таблица |
| Одна корректная строка | Таблица с одной строкой |
| Пустой файл | Ошибка отсутствия данных |
| Два поля вместо трёх | Ошибка количества с номером строки |
| Буква среди чисел | Ошибка преобразования с номером строки |
| Дополнительная пустая строка | Ошибка по принятому формату |
| Отсутствующий файл | `FileNotFoundError` при чтении |
| Неподходящая кодировка | Ошибка декодирования либо необходимость проверить содержимое |

Отдельно проверьте сохранность старого результата: запишите в него контрольный текст, подайте неправильный вход и сравните содержимое после запуска.

<a id="section-30"></a>

## 30. Типичные ошибки и их причины

| Ошибка | Последствие | Что проверить |
|---|---|---|
| Перепутаны индексы строки и столбца | Читается другая ячейка или возникает `IndexError` | Выписать координаты вручную |
| `len(matrix)` используется для обоих размеров | Пропущены столбцы или выход за границу | Пример 2×3 и 3×2 |
| Повторена одна строка через умножение | Меняются несколько видимых строк | Независимость внутренних списков |
| Скопирован только внешний список | Меняется исходная таблица | Копии отдельных строк |
| Накопитель сбрасывается не на том уровне | Неверный общий или построчный результат | Отступы и трассировка |
| Предполагается папка скрипта при относительном пути | Файл не находится | `Path.cwd()` и используемый путь |
| Не указана нужная кодировка | Ошибка чтения или испорченный текст | Кодировку исходного файла |
| Двойной перевод строки при печати | Лишние пустые строки | Содержимое `line` и параметр `end` |
| Файл результата открыт в `w` до проверки | Старый результат потерян | Порядок операций |
| Перехвачены все ошибки без сообщения | Причина проблемы скрыта | Типы в `except` и текст сообщения |
| Пустые строки удалены до проверки | Нарушение формата незаметно | Проверку исходной последовательности строк |

### 30.1. Как искать первую причину

Если таблица в памяти уже имеет неверную форму, начните с чтения и преобразования строк. Если форма правильна, проверьте обход и условия. Если вычисленный текст верен, но файл не появляется, исследуйте путь и этап записи.

Не начинайте одновременно менять все части программы. Временно выведите размеры, номер обрабатываемой строки или `repr(line)`, чтобы найти первый шаг с неожиданным значением.

## 31. Дополнительно: рекурсия

**Рекурсия** — способ описания действия, при котором функция вызывает саму себя. Чтобы такой алгоритм завершился, нужны базовый случай и изменение аргумента, приближающее к нему.

```python
def countdown(number):
    """Вывести обратный отсчёт для небольшого целого number >= 0."""
    if number == 0:
        print("Старт")
        return
    print(number)
    countdown(number - 1)


countdown(3)
```

Результат:

```text
3
2
1
Старт
```

### 31.1. Базовый случай

При аргументе 0 функция печатает «Старт» и завершает вызов. Самовызова в этой ветви нет.

### 31.2. Рекурсивный шаг

При положительном аргументе число уменьшается на единицу. Последовательность вызовов: 3, 2, 1, 0. После завершения последнего вызова завершаются ожидавшие его предыдущие вызовы.

Если начать с отрицательного числа, приведённый алгоритм не приблизится к нулю. Поэтому ограничение аргумента является частью описания. Для больших положительных значений также можно достигнуть предела глубины вызовов и получить `RecursionError`.

### 31.3. Цикл для той же идеи

```python
for number in range(3, 0, -1):
    print(number)
print("Старт")
```

Цикл проще для такого линейного отсчёта и не создаёт цепочку вложенных вызовов. Рекурсия не является автоматическим ускорением и не уменьшает сама по себе количество шагов алгоритма.

<a id="section-32"></a>

## 32. Дополнительно: формат CSV

CSV — текстовый формат табличных данных с разделителями. Поле может содержать разделитель внутри кавычек, поэтому простого `split(",")` недостаточно.

```text
name,note
Датчик-1,"проверен, исправен"
```

Во второй строке два поля, хотя запятых две: одна из них находится внутри текстового поля.

Для чтения используется стандартный модуль `csv`:

```python
import csv

with open("devices.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

Для записи учебного файла:

```python
import csv

with open("demo_devices.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "note"])
    writer.writerow(["Датчик-1", "проверен, исправен"])
```

Параметр `newline=""` позволяет модулю корректно управлять окончаниями строк. Модуль сам оформляет поля с разделителями и кавычками.

CSV определяет запись полей, но не превращает цифры в числа автоматически и не проверяет смысл данных. Преобразования и ограничения по-прежнему относятся к алгоритму программы.

<a id="section-33"></a>

## 33. Дополнительно: запись через отдельный файл

Базовая схема «сначала проверить, затем записать» сохраняет прежний результат при неправильном входе. Чтобы уменьшить риск потери прежнего результата при сбое записи, используют отдельный временный файл.

Общий порядок:

1. Полностью подготовить текст в памяти.
2. Создать временный файл рядом с файлом результата.
3. Записать в него текст и закрыть его.
4. Только после успешной записи заменить файл результата через `os.replace()` или `Path.replace()`.
5. При неудаче удалить ненужный временный файл и показать сообщение.

Файл создают рядом, чтобы замена происходила в пределах одной файловой системы. На системах, поддерживающих атомарную замену, операция позволяет наблюдать старый или новый вариант целиком. Но это не универсальная гарантия сохранности при отключении питания и не замена резервным копиям.

Для первого знакомства достаточно понимать разницу: `with` закрывает файл, а отложенная замена меняет момент, когда новый результат занимает место прежнего.

## 34. Вопросы с разбором

### 34.1. Что обозначает matrix[1][2]?

Третий элемент второй строки. Первый индекс выбирает строку, второй — элемент внутри неё.

### 34.2. Почему нельзя всегда использовать len(matrix) для столбцов?

Эта длина показывает число строк. Количество столбцов определяется длиной строки, а равенство двух размеров бывает только у квадратной таблицы.

### 34.3. Чем отличается [] от [[]]?

Первое значение не содержит строк. Второе содержит одну пустую строку таблицы, представленную внутренним списком.

### 34.4. Почему изменение ячейки иногда видно в двух строках?

Два элемента внешнего списка могут ссылаться на один внутренний список, если он был повторён через умножение. Нужно создавать строки отдельно.

### 34.5. Достаточно ли matrix.copy() для независимого изменения ячеек?

Нет. Копируется внешний список, а внутренние строки остаются общими. Для числовой таблицы копируют каждую строку.

### 34.6. Что означает print(*row)?

Элементы `row` передаются в `print()` как отдельные аргументы. Поэтому выводятся без скобок списка.

### 34.7. Откуда считается путь notes.txt?

От текущей рабочей папки процесса. Она не обязательно совпадает с папкой скрипта.

### 34.8. Создаёт ли Path файл на диске?

Нет. Он описывает путь. Чтение, создание и запись выполняются отдельными операциями.

### 34.9. В какой момент режим w удаляет прежний текст?

При успешном открытии существующего файла для такой записи, до первого `write()`.

### 34.10. Добавляет ли write перевод строки?

Нет. Его указывают явно или заранее включают в записываемый текст.

### 34.11. Чем конец файла отличается от пустой строки внутри него?

`readline()` в конце возвращает `""`. Пустая строка с переводом строки обычно читается как `"\n"`.

### 34.12. Почему после read второй read вернул пустую строку?

Первый вызов прочитал всё оставшееся содержимое и переместил позицию к концу файла.

### 34.13. Проверяет ли int положительность размера?

Нет. Он проверяет возможность получить целое число. Положительность проверяется отдельным условием.

### 34.14. Продолжится ли try с ошибочной команды после except?

Нет. Для повторной попытки нужен явно организованный цикл или новый вызов.

### 34.15. Зачем raise, если есть if?

Условие обнаруживает нарушение, а `raise` сообщает вызывающему коду, что обычный результат получить нельзя. Это позволяет отделить проверку данных от сообщения пользователю.

### 34.16. Почему FileNotFoundError обрабатывают раньше OSError?

Это более частный тип. Если общий обработчик стоит раньше, до специального сообщения о пропавшем файле выполнение не дойдёт.

### 34.17. Зачем проверять данные до открытия результата?

Чтобы некорректный вход не очищал прежний результат открытием в `w`.

### 34.18. Защищает ли with от частичной записи при любом сбое?

Нет. Он организует закрытие файла. Частично записанный результат требует другой схемы сохранения.

### 34.19. Можно ли игнорировать пустые строки при строгом формате?

Только если формат разрешает их пропуск. Иначе удаление скроет нарушение.

### 34.20. Чем базовый случай рекурсии отличается от рекурсивного шага?

В базовом случае функция завершает работу без нового самовызова. Рекурсивный шаг изменяет данные и вызывает функцию снова, приближая к завершению.

## 35. Краткий словарь

| Термин | Значение |
|---|---|
| Вложенный список | Список, элементы которого могут быть списками |
| Матрица | В рассматриваемых примерах — прямоугольная таблица чисел |
| Строка таблицы | Внутренний список элементов одной горизонтальной последовательности |
| Столбец | Элементы с одним индексом столбца из разных строк |
| Ячейка | Один элемент таблицы на пересечении строки и столбца |
| Форма таблицы | Количество строк и столбцов |
| Главная диагональ | Ячейки с равными индексами строки и столбца |
| Вложенный цикл | Цикл внутри тела другого цикла |
| Поверхностная копия | Новый внешний контейнер с прежними ссылками на вложенные объекты |
| Файл | Данные, сохранённые в файловой системе под именем |
| Путь | Указание местоположения файла или папки |
| Рабочая папка | Папка, от которой процесс отсчитывает относительные пути |
| Кодировка | Правило представления текстовых символов байтами |
| UTF-8 | Используемая в примерах кодировка Unicode |
| Файловый объект | Объект, через который программа читает или записывает открытый файл |
| Контекст with | Блок с управляемым входом и выходом, в примерах обеспечивающий закрытие файла |
| Формат данных | Договор о расположении и допустимом содержимом полей и строк |
| Проверка данных | Установление соответствия входа ожидаемому формату и ограничениям |
| Исключение | Сигнал о невозможности обычного завершения операции |
| Обработчик | Код `except`, реагирующий на указанный тип исключения |
| raise | Явное возбуждение исключения |
| Трассировка | Пошаговое отслеживание выполняемых действий и значений |
| Рекурсия | Вызов функцией самой себя |
| Базовый случай | Условие завершения рекурсивного алгоритма без самовызова |
| CSV | Текстовый формат хранения полей табличных данных |

При работе с таблицей сначала определите смысл строк и столбцов, допустимую форму и требования к сохранению исходных данных. При работе с файлом к этому добавляются путь, кодировка и формат. Понятное разделение чтения, проверки, вычисления и записи позволяет объяснить поведение программы и на правильном входе, и при ожидаемых ошибках.
