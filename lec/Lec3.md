## 1. Из чего состоит рабочее место

Для выполнения Python-программы нужен **интерпретатор Python**. Для написания текста нужен **редактор**. Терминал позволяет запускать программу командой. Эти части выполняют разные задачи, хотя среда разработки может объединять их в одном окне.

| Компонент | Назначение |
|---|---|
| Интерпретатор Python | Выполняет программу |
| Редактор кода | Позволяет создавать и сохранять `.py`-файлы |
| Терминал | Принимает команды запуска и показывает результат |
| IDLE | Предоставляет редактор и интерактивную оболочку Python |
| Git | Сохраняет выбранные версии файлов проекта |

IDLE и Geany - разные приложения. Название редактора не определяет язык файла: важно, какое содержимое записано и чем оно запускается.

Используем Python 3, установленный для практических работ. Проверка в терминале:

```text
python --version
```

Если в вашей среде принята команда `py` или `python3`, используйте её последовательно и при проверке, и при запуске файлов. Ответ должен начинаться с `Python 3`. Команда проверки версии вводится в терминал операционной системы, а не в файл программы.

## 2. Интерактивный режим и файл программы

### 2.1. Проверка отдельного выражения

В интерактивной оболочке Python приглашение обычно выглядит как `>>>`:

```text
>>> 2 + 3
5
```

Мы вводим только `2 + 3`. Знаки `>>>` показывают приглашение оболочки и не являются частью выражения.

Этот режим удобен, чтобы быстро проверить операцию. Однако практическая работа должна оставаться в файле, который можно повторно запустить, передать преподавателю и сохранить в Git.

### 2.2. Первая программа

Создайте `hello.py`:

```python
print("Изучаю Python")
print("Лабораторная работа 1")
```

Сохраните файл. В терминале, открытом в его папке, выполните:

```text
python hello.py
```

Результат:

```text
Изучаю Python
Лабораторная работа 1
```

В IDLE можно открыть **File → New File**, сохранить код и выполнить **Run → Run Module**, обычно клавишей F5. Результат появится в окне Shell. Эти действия описаны в [справке IDLE](https://docs.python.org/3/library/idle.html).

Строки программы выполняются по порядку сверху вниз. Измените вторую строку, сохраните и запустите файл снова. В новом запуске должен появиться новый текст.

Если результат не изменился, проверьте, сохранён ли файл и тот ли файл вы запускаете. Совпадающие имена в разных папках часто становятся причиной путаницы.

### 2.3. Выражение в файле не обязано выводиться

В интерактивной оболочке Python показывает результат введённого выражения. В файле строка `2 + 3` вычислится, но сама ничего не выведет. Для видимого результата напишите:

```python
print(2 + 3)
```

## 3. Как читать строку программы

Рассмотрим:

```python
quantity = 3
print("Количество:", quantity)
```

| Фрагмент | Значение |
|---|---|
| `quantity` | Имя переменной |
| `3` | Литерал целого числа: значение прямо в коде |
| `=` | Присваивание |
| `print` | Имя встроенной функции вывода |
| `(...)` | Аргументы вызова функции |
| `"Количество:"` | Строковый литерал |
| `,` | Разделитель аргументов |

**Функция** - операция, которую можно вызвать по имени. В этой лекции используем готовые функции; собственные научимся определять позже. **Аргумент** - значение, которое передаём в вызов. Например, в `print(quantity)` аргументом становится текущее значение переменной.

Кавычки ограничивают текстовый литерал. Они не выводятся вместе с его содержимым. Одинарные и двойные кавычки подходят для обычных строк:

```python
print('Python')
print("Python")
```

Не заменяйте их типографскими кавычками `« »` в коде. Такие кавычки могут быть символами внутри строки, но не заменяют её ограничители.

### Комментарии

Символ `#` вне строки начинает комментарий до конца строки:

```python
# Цена одной тетради в рублях
price = 45
count = 3  # количество тетрадей
print("Заказ #1")
```

В последней строке `#` находится внутри кавычек, поэтому выводится как обычный символ. Комментарий должен пояснять смысл, единицы или причину решения. Запись «умножаем» рядом с `a * b` обычно менее полезна, чем пояснение, что цена указана за одну единицу.

### 3.1. Строки кода, отступы и перенос выражения

В первых программах записывайте каждую команду с новой строки. Точка с запятой в конце не требуется. Пустыми строками можно отделять ввод от вычислений и вывода.

Длинное выражение удобно перенести внутри круглых скобок:

```python
first_cost = 37.5
second_cost = 40.0
delivery = 10.0
total = (
    first_cost
    + second_cost
    + delivery
)
print(total)  # 87.5
```

Это одно выражение, размещённое на нескольких строках. Скобки показывают, что оно продолжается.

Верхнеуровневые команды начинаются без отступа. В дальнейшем отступы будут выделять тела условий, циклов и функций. В курсе используем четыре пробела на уровень и не смешиваем их с табуляцией. Отступ строк продолжения выражения в примере выше помогает чтению и не создаёт отдельного блока выполнения. Правила оформления приведены в [PEP 8](https://peps.python.org/pep-0008/#indentation).

## 4. Переменная и присваивание

**Переменная** в Python - имя, связанное со значением. Запись:

```python
price = 45
count = 3
cost = price * count
print(cost)
```

создаёт связи имён с числами. В строке `cost = price * count` Python:

1. Находит текущие значения `price` и `count`.
2. Умножает 45 на 3.
3. Связывает результат 135 с именем `cost`.

Сначала вычисляется правая часть присваивания, затем изменяется связь имени слева. Знак `=` не устанавливает математическую формулу, которая будет автоматически пересчитываться при будущих изменениях.

```python
price = 45
count = 3
cost = price * count
count = 4
print(cost)  # 135
cost = price * count
print(cost)  # 180
```

После `count = 4` значение `cost` остаётся прежним. Новый результат появляется только после повторного вычисления.

### 4.1. Изменение значения на основе предыдущего

```python
age = 17
age = age + 1
print(age)  # 18
```

Python сначала получает старое значение `age`, прибавляет единицу и связывает с тем же именем результат 18. Для этого действия существует краткая запись `age += 1`, но на первых примерах полезно видеть полное присваивание.

### 4.2. Трассировка

**Трассировка** - последовательная запись того, как меняются значения во время выполнения.

| Выполненная строка | `price` | `count` | `cost` |
|---|---:|---:|---:|
| `price = 45` | 45 | ещё нет | ещё нет |
| `count = 3` | 45 | 3 | ещё нет |
| `cost = price * count` | 45 | 3 | 135 |
| `count = 4` | 45 | 4 | 135 |
| `cost = price * count` | 45 | 4 | 180 |

Таблица помогает проверять понимание программы без запуска. Если имена используются до получения значений, Python обычно сообщит `NameError`.

## 5. Имена переменных

Имя помогает читать программу. Для часов подготовки подходит `study_hours`, для цены единицы - `unit_price`, для общего времени в минутах - `total_minutes`.

В примерах курса используем латинские буквы, цифры и подчёркивания. Имя не начинается с цифры и не содержит пробелов. Python различает регистр: `price`, `Price` и `PRICE` - разные имена.

| Удачное имя | Почему подходит |
|---|---|
| `student_name` | Понятно, чей текст хранится |
| `weekly_hours` | Указан период и единица времени |
| `total_seconds` | Видно, что хранится общее число секунд |
| `capacity` | Соответствует вместимости в условии |

`2price`, `student name` и `total-cost` не подходят как единые имена переменных. Последняя запись читается как вычитание двух имён.

Ключевые слова, например `if`, `for`, `class`, заняты синтаксисом языка. Встроенные имена `print`, `input`, `int` технически можно переопределить, но в учебной программе этого делать не следует: последующий вызов привычной функции перестанет работать ожидаемым образом.

### 5.1. Именованные константы

Если число выражает постоянное правило задачи, ему полезно дать имя. Например, минут в часе всегда 60:

```python
MINUTES_PER_HOUR = 60
total_minutes = 360
total_hours = total_minutes / MINUTES_PER_HOUR
print(total_hours)  # 6.0
```

**Именованная константа** здесь - значение, которое по замыслу программы не должно меняться. В Python такие имена принято записывать заглавными буквами с подчёркиваниями. Это соглашение, а не отдельный неизменяемый тип: обычное присваивание другому значению технически возможно. Соглашение об именах описано в [PEP 8](https://peps.python.org/pep-0008/#constants).

Имена `SECONDS_PER_MINUTE`, `DAYS_PER_WEEK` объясняют происхождение чисел лучше, чем повторение 60 и 7 без пояснения. При этом вводимые цену и количество обычно оставляют переменными: они меняются от заказа к заказу. Выносить константы в отдельный файл пока не требуется.

## 6. Обмен значениями через временную переменную

В работе №1 нужно поменять местами названия двух аудиторий. Простая последовательность `first_room = second_room`, затем `second_room = first_room` потеряет первое название: ко второй строке оба имени уже связаны со вторым значением.

Сохраним первое значение отдельно:

```python
first_room = "А-101"
second_room = "Б-202"

temporary = first_room
first_room = second_room
second_room = temporary

print(first_room)   # Б-202
print(second_room)  # А-101
```

| Этап | `first_room` | `second_room` | `temporary` |
|---|---|---|---|
| Начало | А-101 | Б-202 | ещё нет |
| Сохранили первое | А-101 | Б-202 | А-101 |
| Перенесли второе | Б-202 | Б-202 | А-101 |
| Вернули сохранённое | Б-202 | А-101 | А-101 |

Python поддерживает и более краткий обмен, но в первой работе требуется именно временная переменная. Так становится виден порядок действий и причина сохранения старого значения.

## 7. Типы данных

**Тип** определяет, какое значение перед нами и какие операции с ним имеют смысл.

| Тип | Пример | Применение |
|---|---|---|
| `str` | `"Анна"`, `"17"` | Имя, город, название |
| `int` | `17`, `0`, `-8` | Количество, целые рубли, секунды |
| `float` | `2.5`, `0.0`, `-1.75` | Дробные часы, длины, приближённые вычисления |
| `bool` | `True`, `False` | Результат логического условия |

Заранее объявлять тип переменной в этих примерах не требуется. Тип принадлежит значению, с которым связано имя.

```python
age = 17
age_text = "17"
study_hours = 10.5

print(type(age))          # <class 'int'>
print(type(age_text))     # <class 'str'>
print(type(study_hours))  # <class 'float'>
```

На экране число и строка из цифр иногда выглядят одинаково. `type()` позволяет увидеть различие. Кавычки в исходном коде существенны: `17` - число, `"17"` - текст.

### Динамическая типизация

Одно имя может последовательно связываться со значениями разных типов:

```python
value = 17
print(type(value))  # <class 'int'>
value = "семнадцать"
print(type(value))  # <class 'str'>
```

Это допустимо, но не означает, что Python автоматически подбирает нужную операцию для любой пары значений. Сложение строки с числом по-прежнему требует осмысленного преобразования. В учебных расчётах удобнее сохранять за именем один смысл: `age_text` для исходного текста и `age` для числа.

### 7.1. Одна операция, разные типы

```python
print(2 + 3)        # 5
print("2" + "3")    # 23
print("да" * 3)     # дадада
```

Для чисел `+` выполняет сложение. Для строк он соединяет содержимое. Умножение строки на целое повторяет текст.

Сочетание `"Возраст: " + 17` вызывает ошибку типов. Можно передать текст и число отдельными аргументами `print()` либо оформить f-строку.

### 7.2. Другие значения

В Python есть также `None`, комплексные числа, списки, словари и другие типы. `None` обозначает отсутствие значения в принятом программой смысле; оно не означает автоматически «переменная ещё не создана». Для работ №1–2 достаточно основных типов из таблицы. Коллекции будем вводить тогда, когда задача потребует нескольких однотипно обрабатываемых значений.

### 7.3. Текст на русском языке

Строки `str` в Python 3 поддерживают Unicode: в них можно хранить кириллицу и текст на других языках. Поэтому русские имена, названия предметов и подписи из практической работы являются обычными строками.

Сохраняйте исходный `.py`-файл в UTF-8. Если вместо букв выводятся искажённые символы, нужно проверить кодировку файла и настройки терминала. Возможность хранить русский текст не означает, что в каждом окружении автоматически совпадают настройки отображения.

Латинские имена переменных в курсе - соглашение для удобства чтения и работы с инструментами. Сам Python допускает в идентификаторах многие буквы Unicode.

## 8. Ввод данных и преобразование типов

Функция `input()` ждёт строку от пользователя:

```python
name = input("Как вас зовут? ")
print("Здравствуйте,", name)
```

Текст внутри скобок - приглашение. Введённое пользователем содержимое становится результатом вызова. `input()` возвращает **строку**, в том числе когда пользователь набрал только цифры. Перевод строки от нажатия Enter в возвращаемое значение не входит. Поведение описано в [справке встроенных функций](https://docs.python.org/3/library/functions.html#input).

### 8.1. Ввод целого числа

Подробная форма:

```python
age_text = input("Возраст: ")
age = int(age_text)
print(age + 1)
```

Та же последовательность в одной строке ввода:

```python
age = int(input("Возраст: "))
print(age + 1)
```

Вложенные вызовы читаем изнутри: сначала выполняется `input()`, затем его строковый результат получает `int()`. При вводе `17` программа выводит `18`.

### 8.2. Ввод дробного числа

```python
weekly_hours = float(input("Часов подготовки в неделю: "))
four_weeks = weekly_hours * 4
print(four_weeks)
```

При вводе `10.5` получим `42.0`. Используйте точку как десятичный разделитель. Строка `10,5` не подходит для обычного вызова `float()`.

### 8.3. Преобразование не равно проверке условия

`int("-3")` успешно создаёт целое число -3. Но отрицательное количество может нарушать условие задачи. Поэтому нужно различать:

- подходит ли текст для преобразования;
- входит ли полученное число в допустимый диапазон.

В первых двух работах допустимость входа обеспечивается условием упражнения. Позже добавим проверки диапазона и повторный ввод.

### 8.4. Частые особенности преобразований

| Выражение | Результат |
|---|---|
| `int("17")` | `17` |
| `float("17")` | `17.0` |
| `float("2.5")` | `2.5` |
| `str(17)` | Строка `"17"` |
| `int(2.9)` | `2` |
| `int(-2.9)` | `-2` |

`int()` для дробного числа отбрасывает дробную часть в направлении нуля. Это не математическое округление до ближайшего целого. При этом `int("2.9")` не выполняет такое действие: строка должна описывать целое число и вызов закончится `ValueError`.

Не используйте `eval(input())` для числового ввода. Для задачи получения одного числа существуют прямые преобразования `int()` и `float()`.

## 9. Вывод результата

### 9.1. Несколько аргументов print

```python
price = 45
count = 3
cost = price * count
print("Стоимость:", cost, "руб.")
```

Результат:

```text
Стоимость: 135 руб.
```

По умолчанию `print()` разделяет аргументы пробелами и завершает вывод переводом строки.

Параметр `sep` меняет разделитель:

```python
print("Тетради", 3, 45, 135, sep=" | ")
```

Результат: `Тетради | 3 | 45 | 135`.

Параметр `end` задаёт окончание вывода:

```python
print("Стоимость", end=": ")
print(135)
```

Обе команды вместе выведут `Стоимость: 135` в одной строке. Пустой вызов `print()` выводит перевод строки, помогая отделить части отчёта.

### 9.2. F-строки

F-строка начинается с `f` перед кавычками. В фигурные скобки помещается имя или выражение:

```python
name = "Анна"
age = 17
print(f"Студент: {name}")
print(f"Через четыре года: {age + 4}")
```

Получим `Студент: Анна` и `Через четыре года: 21`. Без буквы `f` скобки останутся обычным текстом.

### 9.3. Два знака после точки

```python
price = 12.5
quantity = 3
cost = price * quantity
print(f"Стоимость: {cost:.2f} руб.")
```

Результат: `Стоимость: 37.50 руб.`.

В записи `{cost:.2f}`:

- `cost` - подставляемое значение;
- `:` - начало описания формата;
- `.2` - два знака после точки;
- `f` - десятичная запись фиксированного формата.

Форматирование меняет представление при выводе. Само значение `cost` от вызова `print()` не меняется.

В исходных PDF встречается также метод `format()`. Для знакомства достаточно эквивалентного примера:

```python
cost = 37.5
print("Стоимость: {:.2f} руб.".format(cost))
print(f"Стоимость: {cost:.2f} руб.")
```

Обе строки выводят одинаковый текст. Для новых примеров будем использовать f-строки.

### 9.4. Кавычки внутри строки

Чтобы вывести кавычки как часть текста, можно выбрать другие внешние кавычки:

```python
print('Магазин "Книга"')
print("Магазин \"Книга\"")
```

Обе команды выводят `Магазин "Книга"`. Во втором варианте используется **экранирование**: обратная косая черта перед кавычкой показывает, что кавычка входит в содержимое строки.

### 9.5. Перевод строки, табуляция и обратная косая черта

| Внутри обычного строкового литерала | Значение |
|---|---|
| `\n` | Перевод строки |
| `\t` | Горизонтальная табуляция |
| `\\` | Одна обратная косая черта |
| `\"` | Двойная кавычка |
| `\'` | Одинарная кавычка |

```python
print("Имя: Анна\nГруппа: ИС-101")
print("Товар\tКоличество")
print("C:\\study\\lab01")
```

Первый вызов выводит две строки, последний - путь `C:\study\lab01`. Табуляция перемещает текст к следующей позиции табуляции, поэтому расстояние зависит от текущего положения и среды. Для отчёта с предсказуемым разделителем проще использовать `sep=" | "`.

В исходном коде `\n` записывается двумя знаками, но внутри обычной строки обозначает один символ перевода строки:

```python
text = "А\nБ"
print(text)
print(len(text))  # 3
```

`len()` возвращает длину строки. Здесь учитываются буква А, перевод строки и буква Б.

### 9.6. Многострочные литералы

Тройные кавычки позволяют записать несколько строк текста непосредственно в коде:

```python
heading = """Карточка студента
Лабораторная работа 1
Данные для проверки"""
print(heading)
```

Переносы и пробелы внутри литерала становятся частью строки. Начало текста сразу после открывающих кавычек в этом примере позволяет избежать лишней пустой строки в начале.

Тройные кавычки создают **строку**, а не специальный многострочный комментарий. Для обычных пояснений к коду используйте `#`.

### 9.7. Raw-строки и пути Windows

В пути `C:\new\test` сочетания `\n` и `\t` совпадают с записью перевода строки и табуляции. В литерале пути можно удвоить обратные косые черты или использовать префикс `r`:

```python
path_regular = "C:\\new\\test"
path_raw = r"C:\new\test"
print(path_regular)
print(path_raw)
```

Обе команды выводят один и тот же путь. Raw-строка остаётся значением типа `str`; префикс влияет на чтение обратных косых черт в литерале. Такой литерал нельзя завершить одиночной обратной косой чертой непосредственно перед закрывающей кавычкой.

Это правило записи кода не требует добавлять `r` к строке, полученной через `input()`: введённые пользователем обратные косые черты не разбираются заново как литерал Python. Правила экранирования и raw-строк описаны в [справке по строковым литералам](https://docs.python.org/3/reference/lexical_analysis.html#string-and-bytes-literals).

## 10. Ввод, расчёт и вывод как части программы

В карточке студента сначала требуется получить все данные, а затем показать результат. Это удобно представить тремя последовательными частями:

```text
Ввод: имя, возраст, часы в неделю
Расчёт: возраст через четыре года, часы за четыре недели, часы в день
Вывод: подписи и вычисленные значения
```

Фрагмент такой программы:

```python
name = input("Имя: ")
age = int(input("Возраст: "))
weekly_hours = float(input("Часов подготовки в неделю: "))

future_age = age + 4
four_weeks_hours = weekly_hours * 4
daily_hours = weekly_hours / 7

print("Учебная карточка")
print(f"Имя: {name}")
print(f"Возраст через четыре года: {future_age}")
print(f"За четыре недели: {four_weeks_hours:.2f} ч")
print(f"В среднем в день: {daily_hours:.2f} ч")
```

Для `Анна`, `17`, `10.5` расчётные результаты равны `21`, `42.00` и `1.50`. Это учебный фрагмент, а не полное решение карточки из работы №1: остальные поля следует добавить самостоятельно.

Не запрашивайте повторно значение, которое уже введено или может быть вычислено. Если программа знает недельную нагрузку, число часов за четыре недели она получает умножением.

## 11. Арифметические операции

| Запись | Операция | Пример | Результат |
|---|---|---|---|
| `a + b` | Сложение | `7 + 2` | `9` |
| `a - b` | Вычитание | `7 - 2` | `5` |
| `a * b` | Умножение | `7 * 2` | `14` |
| `a / b` | Деление | `7 / 2` | `3.5` |
| `a // b` | Деление с округлением вниз | `7 // 2` | `3` |
| `a % b` | Остаток | `7 % 2` | `1` |
| `a ** b` | Возведение в степень | `2 ** 3` | `8` |
| `abs(a)` | Модуль числа | `abs(-7)` | `7` |

Для обычных чисел `int` и `float` операция `/` даёт `float`, даже если число делится без остатка: `8 / 2` возвращает `4.0`.

Целые значения Python не ограничены фиксированным числом десятичных разрядов, хотя память компьютера конечна. Дробные вычисления `float` имеют конечную точность.

Символ `^` не обозначает возведение в степень в Python. Для степени используйте `**`. Умножение нужно указывать явно: математическая запись `2x` превращается в `2 * x`.

## 12. Порядок вычисления выражений

В пределах арифметики этой лекции ориентируемся на порядок:

1. Выражения в скобках.
2. Возведение в степень.
3. Умножение, деление, `//` и `%`.
4. Сложение и вычитание.

Операции одной ступени, кроме степени, в обычной цепочке выполняются слева направо.

```python
print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
print(20 / 5 * 2)    # 8.0
print(20 / (5 * 2))  # 2.0
```

### 12.1. Среднее нескольких чисел

```python
first = 4
second = 7
third = 10
average = (first + second + third) / 3
print(average)  # 7.0
```

Без скобок делилась бы только последняя величина. Программа при этом могла бы успешно запуститься, но решить другую задачу.

### 12.2. Степень и знак минуса

```python
print(-2 ** 2)     # -4
print((-2) ** 2)   # 4
print(2 ** 3 ** 2) # 512
```

В первом выражении сначала возводится в квадрат 2, затем применяется минус. Во втором основание степени равно -2. Цепочка степеней группируется справа: `2 ** (3 ** 2)`.

Если смысл выражения может быть прочитан двояко, используйте скобки. Краткая запись ценна только тогда, когда её правильно понимают.

## 13. Целочисленное деление и остаток

Пусть 17 предметов раскладывают в коробки по 5. Полностью заполняются 3 коробки, остаётся 2 предмета:

```python
total = 17
capacity = 5
full_boxes = total // capacity
remaining = total % capacity
print(full_boxes)  # 3
print(remaining)   # 2
```

Связь результатов:

```text
17 = 3 × 5 + 2
общее количество = полные коробки × вместимость + остаток
```

Для целых `a` и `b`, где `b` не равно нулю, выполняется равенство `a == (a // b) * b + a % b`. Знак `==` в этой записи означает сравнение; присваивание по-прежнему обозначается одним `=`.

### 13.1. Отрицательные числа

`//` округляет частное вниз, в сторону меньшего числа:

```python
print(-7 / 2)    # -3.5
print(-7 // 2)   # -4
print(-7 % 2)    # 1
print(int(-3.5)) # -3
```

Поэтому `//` нельзя описывать просто как «убрать дробную часть». У отрицательных чисел такое объяснение даёт неверный ответ. Проверяем: `-4 * 2 + 1` равно `-7`.

При положительном целом делителе остаток неотрицателен и меньше делителя. Эти свойства удобно использовать в разложении времени. Основные числовые операции рассмотрены в [учебнике Python](https://docs.python.org/3/tutorial/introduction.html#numbers).

### 13.2. Нулевой делитель

Операции `/`, `//` и `%` не допускают нулевой делитель. В работе №2 вместимость должна быть строго положительной. С нулевым общим количеством работать можно: это другая величина и другое ограничение.

## 14. Разложение времени на часы, минуты и секунды

В одном часе 3600 секунд, в одной минуте 60. Для общего времени сначала отделяем часы, затем работаем с остатком:

```python
total_seconds = 3671

hours = total_seconds // 3600
after_hours = total_seconds % 3600
minutes = after_hours // 60
seconds = after_hours % 60

print(f"{hours} ч {minutes} мин {seconds} с")
```

Пошаговый расчёт:

| Величина | Расчёт | Значение |
|---|---|---:|
| Полные часы | `3671 // 3600` | 1 |
| Остаток после часов | `3671 % 3600` | 71 |
| Минуты в остатке | `71 // 60` | 1 |
| Оставшиеся секунды | `71 % 60` | 11 |

Проверка восстановлением: `1 * 3600 + 1 * 60 + 11` равно 3671.

Для пользовательского ввода замените первую строку на `total_seconds = int(input("Всего секунд: "))`. Число часов в этой задаче может быть больше 23: мы раскладываем длительность, а не показываем время суток. Например, 90000 секунд - это 25 часов.

Характерные границы: 0, 59, 60, 3599, 3600. На них видно, правильно ли программа выделяет полную минуту или полный час.

## 15. Минимальное число упаковок

Полностью заполненные упаковки и число упаковок для всех предметов - разные результаты. Для 21 предмета и вместимости 10 получаем две полные упаковки и остаток 1, но для размещения всего объёма нужны три упаковки.

Для целых `total >= 0` и `capacity > 0`:

```python
total = 21
capacity = 10

full_units = total // capacity
remainder = total % capacity
needed_units = (total + capacity - 1) // capacity

print(f"Полных: {full_units}")
print(f"Остаток: {remainder}")
print(f"Всего требуется: {needed_units}")
```

Почему прибавляется `capacity - 1`? Если объём делится точно, прибавка меньше целой упаковки и частное не увеличивается. Если остаток положителен, прибавка вместе с ним достигает вместимости, и частное увеличивается на единицу.

| `total` | `capacity` | Полных | Остаток | Нужно всего |
|---:|---:|---:|---:|---:|
| 0 | 10 | 0 | 0 | 0 |
| 1 | 10 | 0 | 1 | 1 |
| 20 | 10 | 2 | 0 | 2 |
| 21 | 10 | 2 | 1 | 3 |

Формула применима к указанным целым входным данным. Она позволяет решить варианты работы №2 без условий и без перевода больших целых чисел во `float`.

## 16. Дробные числа и точность

В `float` многие десятичные дроби хранятся приближённо. Поэтому:

```python
value = 0.1 + 0.2
print(value)          # 0.30000000000000004
print(f"{value:.2f}") # 0.30
print(value)          # 0.30000000000000004
```

Форматирование сделало вывод удобнее, но не заменило внутреннее значение. Это ожидаемая особенность двоичной арифметики, рассмотренная в [документации о числах с плавающей точкой](https://docs.python.org/3/tutorial/floatingpoint.html).

Для целого количества предметов нужен `int`. Для дробной длины или среднего числа часов подходит `float`. В задании №1 цены вводятся дробными числами, а денежный вывод оформляется с двумя знаками. В задании №2 цена дана в целых рублях, поэтому её удобно хранить как `int`. Выбор типа следует условию конкретной задачи.

Если цена задана точным целым количеством копеек, целая арифметика сохраняет точность такого расчёта. Не следует автоматически получать копейки через `int(price * 100)` из произвольного `float`: приближение может повлиять на отбрасываемую часть.

`round(value, 2)` возвращает округлённое значение, а формат `:.2f` создаёт его текстовое представление. Для требования «вывести два знака после точки» достаточно форматирования. Не округляйте каждый промежуточный шаг без требования задачи: накопленная погрешность может увеличить отличие конечного ответа.

## 17. Перевод математической формулы в программу

Перед написанием длинного выражения определите входные величины, их единицы и допустимые значения. Затем выпишите результат через эти величины.

Для средней продолжительности занятия:

```text
средняя продолжительность = общее время / количество занятий
```

В программе:

```python
total_minutes = 270
lessons = 3
average_minutes = total_minutes / lessons
print(f"Средняя продолжительность: {average_minutes:.2f} мин")
```

Здесь `lessons` должно быть положительным. Если это число может быть нулём, условие задачи обязано отдельно определить результат такого случая. В первой последовательной версии просто работаем в заданной области допустимого ввода.

Для дроби скобки должны охватывать весь числитель и весь знаменатель. Математическая запись `(a + b) / (c + d)` превращается в такую же группировку в Python. Выражение `a + b / c + d` означает другой порядок действий.

### 17.1. Единицы измерения

Пусть за неделю проходят три занятия по 90 минут и два по 45 минут:

```python
first_count = 3
first_duration = 90
second_count = 2
second_duration = 45
available_hours = 10

first_minutes = first_count * first_duration
second_minutes = second_count * second_duration
total_minutes = first_minutes + second_minutes
total_hours = total_minutes / 60
free_hours = available_hours - total_hours
four_weeks_hours = total_hours * 4

print(f"За неделю: {total_minutes} мин, или {total_hours:.2f} ч")
print(f"Свободно: {free_hours:.2f} ч")
print(f"За четыре недели: {four_weeks_hours:.2f} ч")
```

Получим 360 минут, 6.00 часа, 4.00 свободного часа и 24.00 часа за четыре недели.

Нельзя непосредственно вычитать минуты из часов. Промежуточные имена с единицами помогают увидеть такую ошибку: `available_hours - total_minutes` выглядит подозрительно ещё до запуска.

## 18. Модуль math

import math

### 18.1. Диагональ прямоугольника

По теореме Пифагора диагональ равна квадратному корню из суммы квадратов сторон:

```python
import math

width = float(input("Ширина: "))
height = float(input("Высота: "))
diagonal = math.sqrt(width ** 2 + height ** 2)
print(f"Диагональ: {diagonal:.2f}")
```

Для сторон 3 и 4 ответ `5.00`. Обе стороны заданы в одинаковых единицах, и диагональ получается в них же. По условию рассматриваем положительные стороны.

### 18.2. Длина окружности и площадь круга

```python
import math

radius = 1.0
circumference = 2 * math.pi * radius
area = math.pi * radius ** 2

print(f"Длина окружности: {circumference:.2f}")
print(f"Площадь: {area:.2f}")
```

Результаты `6.28` и `3.14`. Если радиус задан в метрах, длина будет в метрах, площадь - в квадратных метрах.

### 18.3. Радианы и градусы

```python
import math

angle_degrees = 60
angle_radians = math.radians(angle_degrees)
result = math.cos(angle_radians)
print(f"Косинус: {result:.2f}")  # Косинус: 0.50
```

Вызов `math.cos(60)` вычислял бы косинус 60 радиан. Программа могла бы выполниться без ошибки, но дать результат для другого угла.

### 18.4. Составное выражение из исходной работы №2

В PDF работа с формулами включает выражения с корнем, тригонометрией и экспонентой. Их удобнее разбивать на части:

```python
import math

x = 10
t = 1
numerator = 9 * math.pi * t + 10 * math.cos(x)
denominator = math.sqrt(t) - abs(math.sin(t))
result = numerator / denominator * math.exp(x)

print(f"Результат: {result:.2f}")
```

Здесь `x` и `t` в тригонометрических функциях интерпретируются как радианы. Для действительного корня требуется `t >= 0`, а знаменатель не должен равняться нулю. Пример с `x = 10`, `t = 1` удовлетворяет этим ограничениям.

Этот разбор дополнительный к актуальной работе №2. Его цель - научиться переносить формулу по частям. Имена `numerator` и `denominator` позволяют отдельно проверить числитель и знаменатель. Область допустимых данных остаётся частью задачи даже после переноса формулы в код.

## 19. Полный пример: покупка и сдача

В работе №2 цена дана в целых рублях, количество неотрицательно, переданной суммы достаточно для оплаты. Сначала составим модель.

| Роль | Величина | Тип |
|---|---|---|
| Вход | Цена одной тетради в рублях | `int` |
| Вход | Количество тетрадей | `int` |
| Вход | Переданная сумма в рублях | `int` |
| Результат | Цена, умноженная на количество | `int` |
| Результат | Переданная сумма минус стоимость | `int` |

Программа:

```python
price = int(input("Цена тетради в целых рублях: "))
count = int(input("Количество: "))
paid = int(input("Переданная сумма в рублях: "))

cost = price * count
change = paid - cost

print(f"Стоимость: {cost} руб.")
print(f"Сдача: {change} руб.")
```

Для 45 рублей, трёх тетрадей и оплаты 200 рублей вручную получаем `45 * 3 = 135` и `200 - 135 = 65`. Именно эти значения должны появиться в выводе.

### 19.1. Расширение до двух позиций

В индивидуальном задании работы №1 вводятся две позиции заказа, доставка и оплата. Структура расчёта расширяется:

```text
стоимость первой позиции = первая цена × первое количество
стоимость второй позиции = вторая цена × второе количество
товары = стоимость первой + стоимость второй
к оплате = товары + доставка
количество единиц = первое количество + второе количество
сдача = внесённая сумма − сумма к оплате
```

Это план вычислений. Имена, ввод всех полей и строки отчёта нужно составить самостоятельно. Если добавляется скидка из дополнительного задания, сначала вычисляют скидку от стоимости товаров, затем прибавляют доставку. В условии скидка на доставку не распространяется.

## 20. Как читать ошибки

Ошибки полезно разделить по моменту появления и причине.

| Вид | Пример причины | На что смотреть |
|---|---|---|
| `SyntaxError` | Не закрыта кавычка или скобка | Запись указанной строки и соседних строк |
| `NameError` | Опечатка в имени или использование до присваивания | Где и под каким именем получено значение |
| `TypeError` | Сложение строки и числа | Типы аргументов операции |
| `ValueError` | `int()` получает текст `"два"` | Содержание строки и нужное преобразование |
| `ZeroDivisionError` | Нулевой делитель | Формула и ограничения входа |
| Логическая ошибка | Неверные скобки или смешение минут и часов | Ручной расчёт и промежуточные значения |

При исключении прочитайте последнюю строку сообщения, затем найдите имя файла и номер строки. Для простых учебных программ этого часто достаточно, чтобы сузить поиск. Не все ошибки исправляются в том месте, где выполнение остановилось: неподходящее значение могло появиться раньше.

### 20.1. Намеренно ошибочный пример

Этот фрагмент приведён для анализа, а не для копирования в рабочее решение:

```text
age = input("Возраст: ")
print(age + 1)
```

При вводе `17` переменная `age` содержит строку. Операция со строкой и целым числом вызовет `TypeError`. Исправление - получить число через `int(input(...))`.

Другой пример, `"2" + "3"`, не вызывает исключения. Его результат `"23"` корректен для строк, но не соответствует задаче сложения чисел. Значит, отсутствие ошибки выполнения ещё не доказывает правильность решения.

## 21. Проверка результата

Проверка начинается до запуска: выбираем входные данные и вручную определяем ожидаемый результат. Если сначала запустить программу и просто переписать её вывод в графу «ожидалось», проверка не будет независимой.

Для покупки:

| Случай | Цена | Количество | Оплата | Стоимость | Сдача |
|---|---:|---:|---:|---:|---:|
| Обычная покупка | 45 | 3 | 200 | 135 | 65 |
| Точная оплата | 45 | 3 | 135 | 135 | 0 |
| Нет товаров | 45 | 0 | 100 | 0 | 100 |
| Нулевая цена | 0 | 3 | 20 | 0 | 20 |

Для перевода времени проверьте значения непосредственно до и после перехода в новую единицу. Для упаковок - пустой объём, точную кратность и один предмет сверх вместимости.

### 21.1. Свойства, которые должны сохраняться

Иногда удобно проверять не только конкретный ответ, но и связь величин:

- стоимость плюс сдача равна переданной сумме;
- часы, минуты и секунды восстанавливают исходную длительность;
- полные упаковки, умноженные на вместимость, плюс остаток дают общий объём;
- при обмене значениями сохраняются оба исходных названия;
- повторный запуск с теми же данными даёт тот же расчётный результат.

Для дробного результата сравнивайте с ожидаемой точностью задачи. Формат `:.2f` задаёт вид отображения, а не требование точного равенства внутренних двоичных значений.

### 21.2. Промежуточный вывод

Если итог неверен, временно выведите части расчёта:

```python
first_count = 3
first_price = 12.5
second_count = 2
second_price = 20.0

first_cost = first_count * first_price
second_cost = second_count * second_price
goods_cost = first_cost + second_cost

print("Первая позиция:", first_cost)
print("Вторая позиция:", second_cost)
print("Товары:", goods_cost)
```

Ожидаем 37.5, 40.0 и 77.5. Если неверно уже первое значение, нет смысла начинать поиск с форматирования итоговой строки.

После исправления повторите все выбранные проверки. Это помогает заметить, что исправление одного случая не нарушило другой.

### Порядок самостоятельной работы

1. Выписать входные данные, результаты и ограничения задачи.
2. Выбрать тип и единицу измерения каждой величины.
3. Рассчитать один небольшой пример вручную.
4. Записать последовательность: ввод, расчёт, вывод.
5. Запустить программу и сравнить с ожидаемым ответом.

Для первой работы используется `lab01`, для второй - `lab02`. В `README.md` указываются команда запуска, входные данные, ожидаемые и фактические результаты. Если работа требует несколько файлов, сохраняйте их под именами из задания. Скриншот дополняет исходный код, но не заменяет его.

После проверки можно сохранить законченное изменение в Git. Текст сообщения должен объяснять результат работы, например «Добавлен перевод секунд в часы, минуты и секунды».

## 23. Краткий словарь

| Термин | Значение |
|---|---|
| Интерпретатор | Программа, выполняющая Python-код |
| Исходный файл | Текст программы, в нашем случае `.py` |
| Литерал | Значение, записанное непосредственно в коде |
| Именованная константа | Имя значения, которое по соглашению программы не меняют |
| Переменная | Имя, связанное со значением |
| Присваивание | Вычисление правой части и связывание результата с именем |
| Тип | Характеристика значения и допустимых операций |
| Выражение | Запись, при вычислении которой получается значение |
| Аргумент | Значение, передаваемое в вызов функции |
| Преобразование | Получение значения нужного типа из исходного |
| Форматирование | Создание текстового представления значения |
| Экранирование | Специальная запись кавычки, перевода строки и других символов в литерале |
| Raw-строка | Строковый литерал с префиксом `r`, меняющим обработку обратных косых черт |
| Модуль | Организация связанных функций и других объектов |
| Трассировка | Пошаговое отслеживание значений |
| Граничная проверка | Проверка на краю допустимого диапазона или переходе между случаями |

Основная идея лекции: программа должна точно переводить входные данные в требуемый результат. Для этого нужно понимать типы, порядок вычислений и ограничения задачи, а затем сопоставлять результат с независимым расчётом.

Следующая тема - условия и логические выражения. Они позволят выбирать действие по данным, например отдельно обрабатывать недопустимое количество или неизвестную операцию калькулятора. Последовательность курса приведена в [плане лекций по Python](План_лекций_Python_Практические_1-12.md).
