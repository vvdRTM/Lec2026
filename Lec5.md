# Лекция 5. Python: строки и списки

В предыдущей лекции мы научились выбирать ветвь выполнения и повторять действия в цикле. Теперь применим эти инструменты к последовательностям: сначала к тексту, затем к наборам чисел.

**Строка** хранит последовательность символов и не изменяется после создания. **Список** хранит последовательность элементов и допускает изменение: в него можно добавлять значения, заменять их и удалять. У строк и списков много общих идей: длина, индексы, срезы, перебор и проверка принадлежности. Главное различие связано с изменяемостью.

В работе со строками важно заранее определить правила: учитывать ли регистр, пробелы и пунктуацию, что считать словом. В работе со списками важно решить, можно ли менять исходные данные или требуется построить независимый результат.

## 1. Строка как последовательность символов

Значение типа `str` представляет текст:

```python
text = "Python"
print(type(text))  # <class 'str'>
```

Строка состоит из символов в определённом порядке. В строке `"Python"` шесть символов:

| Индекс | 0 | 1 | 2 | 3 | 4 | 5 |
|---:|---|---|---|---|---|---|
| Символ | `P` | `y` | `t` | `h` | `o` | `n` |

Пробел, знак препинания и перевод строки тоже являются символами. Для строки `"Я учусь"` функция `len()` учитывает пробел:

```python
text = "Я учусь"
print(len(text))  # 7
```

В приведённых примерах каждая русская буква считается одним элементом строки. Точнее, Python считает кодовые точки Unicode. Для привычных букв это совпадает с видимыми символами, но некоторые эмодзи и сочетания буквы с отдельным знаком могут состоять из нескольких элементов. Количество байтов в файле — другая величина, и `len(text)` его не измеряет.

### 1.1. Число и текст из цифр

```python
number = 24
text = "24"

print(number + 1)  # 25
print(text + "1")  # 241
print(len(text))   # 2
```

Кавычки меняют тип данных: `24` является числом, а `"24"` состоит из двух текстовых символов. К строке применимы длина и индексы, к числу — числовая арифметика. Если значение получено через `input()`, оно остаётся строкой до явного преобразования.

**Самопроверка:** сколько символов в строке `"7 8"`? Три: цифра, пробел и цифра.

### 1.2. Пустая строка

Пустая строка записывается как две кавычки без символов между ними:

```python
text = ""
print(len(text))  # 0
```

Пустая строка является допустимым значением. Однако у неё нет символов, поэтому обращение `text[0]` вызовет `IndexError`.

### 1.3. Строковый литерал и переменная

```python
course = "Python"
```

`"Python"` - строковый литерал, а `course` - имя переменной. Кавычки входят в запись литерала, но не являются частью значения.

Можно использовать одинарные или двойные кавычки:

```python
first = "Python"
second = 'Python'
print(first == second)  # True
```

Выбирайте вариант, который позволяет проще записать содержимое строки.

## 2. Индексы символов

Индекс первого элемента последовательности равен нулю:

```python
text = "Python"

print(text[0])  # P
print(text[1])  # y
print(text[5])  # n
```

Индекс указывается в квадратных скобках. Результат `text[index]` тоже является строкой, но длиной в один символ.

Длина отвечает на вопрос «сколько элементов?», индекс — «какой элемент получить?». У шести символов шесть позиций с индексами `0, 1, 2, 3, 4, 5`. Число 6 показывает количество, но не является допустимым положительным индексом этой строки.

Индекс можно вычислить:

```python
text = "Python"
last_index = len(text) - 1
print(text[last_index])  # n
```

Для непустой строки это равносильно `text[-1]`.

### 2.1. Отрицательные индексы

Отрицательные индексы отсчитываются с конца:

| Индекс | -6 | -5 | -4 | -3 | -2 | -1 |
|---:|---|---|---|---|---|---|
| Символ | `P` | `y` | `t` | `h` | `o` | `n` |

```python
text = "Python"

print(text[-1])  # n
print(text[-2])  # o
```

Индекс `-1` обозначает последний символ.

### 2.2. Допустимые границы

Для строки длины `n` допустимы положительные индексы от `0` до `n - 1` и отрицательные от `-n` до `-1`.

```python
text = "Python"
print(text[6])
```

Такой код вызовет `IndexError`, потому что последнему символу соответствует индекс 5.

Перед обращением к первому или последнему символу строки неизвестной длины нужно убедиться, что она не пуста:

```python
if text:
    print(text[0], text[-1])
else:
    print("Нет символов")
```

Условие `if text:` для строки означает «строка непустая». Равносильная по смыслу запись — `if len(text) > 0:`. Обе проверки разрешают выполнить индексирование только тогда, когда хотя бы один символ существует.

Пробел не означает пустоту: `" "` имеет длину 1. Поэтому строка из пробелов проходит проверку `if text:`. Если нужно проверить наличие текста после удаления пробелов по краям, сначала создают очищенную строку.

## 3. Срезы строк

Срез извлекает часть последовательности:

```python
text[start:stop:step]
```

`start` входит в результат, `stop` не входит. Значение `step` задаёт шаг.

```python
text = "Python"

print(text[0:2])  # Py
print(text[2:6])  # thon
print(text[1:5])  # ytho
```

Срез `[0:2]` включает символы с индексами 0 и 1. Индекс 2 является исключённой правой границей.

Удобно читать `text[1:5]` словами: «начать с позиции 1 и брать символы, пока не дошли до позиции 5». Для `Python` последовательно получаем `y`, `t`, `h`, `o`. При шаге 1 и корректных границах число выбранных символов равно `stop - start`, здесь `5 - 1 = 4`.

Срез возвращает строку, которую можно сразу вывести или сохранить под новым именем. Исходное значение при этом не меняется.

### 3.1. Пропущенные границы

```python
text = "Python"

print(text[:3])   # Pyt
print(text[3:])   # hon
print(text[:])    # Python
```

Пропущенное начало означает начало строки, пропущенный конец - конец строки.

### 3.2. Шаг среза

```python
text = "Python"

print(text[::2])  # Pto
print(text[1::2]) # yhn
```

Первый пример берёт символы с индексами 0, 2, 4. Второй начинается с индекса 1.

### 3.3. Обратный порядок

Отрицательный шаг позволяет пройти строку справа налево:

```python
text = "Python"
reversed_text = text[::-1]
print(reversed_text)  # nohtyP
```

Эта запись используется в задании на палиндром.

### 3.4. Срез безопаснее отдельного индекса

Срез с выходящей за длину границей не вызывает ошибку:

```python
text = "abc"
print(text[:100])  # abc
```

Срез пустой строки также допустим:

```python
text = ""
print(text[::-1])  # пустая строка
```

Отдельный индекс за границей приводит к `IndexError`, а срез ограничивается доступной частью.

### 3.5. Пустой срез и направление

```python
text = "Python"
print(repr(text[4:2]))  # ''
print(text[4:2:-1])    # oh
```

В первом случае шаг по умолчанию равен 1. Начало 4 уже находится правее остановки 2, поэтому вперёд пройти нельзя и получается пустая строка. Во втором случае шаг отрицательный: выбираются индексы 4 и 3, а индекс 2 не включается.

Шаг 0 недопустим: он не позволяет перейти к следующей позиции. Для начального изучения достаточно уверенно использовать обычный срез, `::2` и `[::-1]`.

## 4. Неизменяемость строк

После создания строку нельзя изменить по индексу:

```text
text = "кот"
text[0] = "р"
```

Python выдаст `TypeError`. Строка является **неизменяемым** объектом.

Чтобы получить другое значение, нужно создать новую строку:

```python
text = "кот"
new_text = "р" + text[1:]

print(text)      # кот
print(new_text)  # рот
```

Исходная строка не изменилась.

### 4.1. Методы возвращают новое значение

```python
text = "Python"
text.lower()
print(text)  # Python
```

Вызов `lower()` создал новую строку, но программа её не сохранила.

Правильные варианты:

```python
lower_text = text.lower()
```

или:

```python
text = text.lower()
```

Во втором случае имя `text` связывается с новой строкой. Старая строка всё равно не менялась внутри.

### 4.2. Имя переменной и объект

Объект — само значение с его типом и доступными действиями. Имя переменной позволяет обратиться к нему. Неизменяемость относится к объекту строки, а не к возможности присвоить имени другое значение.

```python
original = "PyThOn"
text = original
text = text.lower()

print(original)  # PyThOn
print(text)      # python
```

Сначала оба имени обозначают исходную строку. Затем результат `lower()` связывается только с именем `text`. Имя `original` продолжает обозначать исходное значение.

## 5. Основные методы строк

**Метод** — действие, к которому обращаются через объект и точку. В выражении `text.lower()` слева от точки находится строка, справа — имя действия, а скобки запускают его.

Сравните `len(text)` и `text.lower()`. В первом случае строка передаётся аргументом общей функции `len()`. Во втором используется метод самого строкового объекта. Наличие скобок важно в обоих случаях.

Методы возвращают результаты разных типов. Например, `lower()` возвращает строку, `count()` — целое число, а `startswith()` — логическое значение. После вызова полезно спрашивать: «Что именно я получил и где использую результат?»

| Запись | Результат |
|---|---|
| `text.strip()` | Новая строка без пробельных символов по краям |
| `text.lower()` | Новая строка в нижнем регистре |
| `text.upper()` | Новая строка в верхнем регистре |
| `text.replace(old, new)` | Новая строка с заменами |
| `text.count(part)` | Число неперекрывающихся вхождений |
| `text.startswith(part)` | Проверка начала строки |
| `text.endswith(part)` | Проверка конца строки |
| `text.split()` | Список частей строки |

### 5.1. strip

```python
text = "  Python  \n"
cleaned = text.strip()

print(repr(cleaned))  # 'Python'
```

Без аргумента `strip()` удаляет пробельные символы только по краям. Пробелы внутри строки сохраняются.

С аргументом метод удаляет указанные символы с обоих краёв:

```python
word = "...Python,!"
cleaned = word.strip(".,!?;:")
print(cleaned)  # Python
```

Аргумент задаёт набор отдельных символов, а не одну обязательную подстроку.

В примере `repr(cleaned)` нужен, чтобы увидеть строку с кавычками и отличить пустую строку от незаметного пробела. Обычный `print(cleaned)` показывает содержимое, а `print(repr(cleaned))` — его текстовое представление. Это удобно при отладке пробелов и переводов строк.

### 5.2. lower и upper

```python
text = "PyThOn"

print(text.lower())  # python
print(text.upper())  # PYTHON
```

Приведение к одному регистру помогает сравнивать текст без учёта регистра.

### 5.3. startswith и endswith

```python
word = "армия"

print(word.startswith("а"))  # True
print(word.endswith("я"))    # True
```

Эти методы читаются яснее, чем ручное обращение к первому и последнему символу. Они безопасны и для пустой строки: результат будет `False`, а не ошибка индекса.

Здесь проверяются непустые префикс и суффикс. Есть особый случай: любая строка начинается и заканчивается пустой строкой, поэтому `"".startswith("")` вернёт `True`.

## 6. Поиск и подсчёт в строке

Оператор `in` проверяет наличие подстроки:

```python
text = "Изучаем Python"

print("Python" in text)  # True
print("Java" in text)    # False
```

Подстрока может содержать один или несколько символов.

Отрицание записывается через `not in`:

```python
if "а" not in word:
    print("Буквы а нет")
```

### 6.1. Метод count

```python
text = "банан"

print(text.count("а"))   # 2
print(text.count("ан"))  # 2
```

`count()` считает неперекрывающиеся вхождения. Для лабораторной работы важны подсчёт двоеточий и букв в очищенном слове.

Слово «неперекрывающиеся» означает, что один уже учтённый участок не используется повторно:

```python
print("aaaa".count("aa"))  # 2
```

Первая пара занимает позиции 0–1, вторая — 2–3. Пара с началом на позиции 1 отдельно не учитывается, потому что пересекается с первой. Для подсчёта отдельной буквы эта особенность обычно не влияет на решение.

### 6.2. Поиск чувствителен к регистру

```python
text = "Python"

print("p" in text)          # False
print("p" in text.lower())  # True
```

Если регистр нужно игнорировать, сначала нормализуйте строку.

### 6.3. Слово и подстрока

В строке `"котёнок"` содержится подстрока `"кот"`, но это не отдельное слово. Проверка `"кот" in text` ищет последовательность символов и не анализирует границы слов.

Правило того, что считать словом, должно быть задано условием задачи. В лабораторной работе слово - результат `split()` после обработки краёв.

## 7. Разбиение и соединение строк

Метод `split()` без аргумента разбивает строку по последовательностям пробельных символов:

```python
text = "  Один   два\tтри  "
words = text.split()

print(words)  # ['Один', 'два', 'три']
```

Пробелы по краям не создают пустых элементов. Несколько пробельных символов подряд работают как один разделитель.

### 7.1. split с явным разделителем

```python
text = "a::b:"
parts = text.split(":")

print(parts)  # ['a', '', 'b', '']
```

При явном разделителе соседние двоеточия создают пустую часть. Это поведение отличается от `split()` без аргумента.

### 7.2. join

Метод `join()` соединяет строки, вставляя разделитель между ними:

```python
words = ["Один", "два", "три"]
result = " ".join(words)

print(result)  # Один два три
```

Метод вызывается у строки-разделителя. Выражение читается как «соединить элементы `words` пробелом».

```python
print("-".join(["2026", "10", "07"]))  # 2026-10-07
```

`join()` ожидает строки. Список чисел нужно предварительно преобразовать в строки.

### 7.3. Как прочитать цепочку преобразований

```python
text = "красный зелёный синий"
parts = text.split()
result = " / ".join(parts)
print(result)  # красный / зелёный / синий
```

| Шаг | Значение | Тип |
|---|---|---|
| До разбиения | `"красный зелёный синий"` | `str` |
| После `split()` | `['красный', 'зелёный', 'синий']` | `list` |
| После `join()` | `"красный / зелёный / синий"` | `str` |

Разделитель появляется между элементами. Перед первым и после последнего он не добавляется. Если элемент всего один, разделитель не используется ни разу.

Отдельно различайте `"".split()` и `"".split(":")`: первый вызов даёт `[]`, второй — `['']`. Без аргумента выделяются непустые части по пробельным символам, а явный разделитель задаёт другое правило.

<a id="section-8"></a>

## 8. Нормализация текста

Нормализация приводит разные варианты записи к единой форме. В первом задании работы №5 нужно:

- убрать пробельные символы по краям;
- заменить последовательности пробельных символов внутри одним пробелом;
- сохранить регистр;
- вывести длины и количество слов.

```python
text = input("Введите текст: ")
words = text.split()
normalized = " ".join(words)

print(f"Исходная длина: {len(text)}")
print(f"Новая длина: {len(normalized)}")
print(f"Текст: {normalized}")
print(f"Слов: {len(words)}")
```

Для ввода:

```text
  Один   два  
```

получаем строку `"Один два"`, длину 8 и два слова.

### 8.1. Почему достаточно split и join

`split()` без аргумента:

1. игнорирует пробельные символы по краям;
2. объединяет последовательность пробельных символов в один раздел;
3. возвращает только непустые части.

`" ".join(words)` вставляет ровно один обычный пробел между частями.

### 8.2. Пустой ввод

```python
text = "   "
words = text.split()
normalized = " ".join(words)

print(words)       # []
print(normalized)  # пустая строка
print(len(words))  # 0
```

Алгоритм не требует отдельной ветви для создания результата. Пустой список соединяется в пустую строку.

### 8.3. Пошаговое состояние данных

Для строки `"  Один   два  "` последовательно получаем:

| Переменная или выражение | Значение |
|---|---|
| `text` | Строка длиной 14, включая все пробелы |
| `words` | `['Один', 'два']` |
| `len(words)` | `2` |
| `normalized` | `"Один два"` |
| `len(normalized)` | `8` |

У исходной строки два пробела в начале, три между словами и два в конце. Вместе с семью буквами это 14 символов. В результате семь букв и один пробел — 8 символов.

Обратите внимание на разные вопросы: `len(text)` считает символы, а `len(words)` считает элементы списка. Ответ зависит от типа объекта, переданного в `len()`.

<a id="section-9"></a>

## 9. Правила сравнения текста

До написания программы нужно решить, какие различия учитывать.

| Правило | Возможное действие |
|---|---|
| Игнорировать регистр | `lower()` |
| Игнорировать пробелы по краям | `strip()` |
| Игнорировать все обычные пробелы | `replace(" ", "")` |
| Свести группы пробелов к одному | `" ".join(text.split())` |
| Удалить заданную пунктуацию с краёв слова | `strip(".,!?;:")` |
| Сохранить пунктуацию | Не удалять её |

Нельзя автоматически применять все способы очистки. Они меняют смысл задачи.

Например, в палиндроме лабораторной работы игнорируются регистр и обычные пробелы, но пунктуация сравнивается как есть. Значит, `"А!"` после очистки остаётся `"а!"` и не является палиндромом.

### 9.1. Исходное и нормализованное значение

Полезно хранить отдельные имена:

```python
original = input("Текст: ")
normalized = original.lower().replace(" ", "")
```

Так можно вывести исходную строку, сравнить длины и не потерять введённые данные.

<a id="section-10"></a>

## 10. Проверка палиндрома

Палиндром одинаково читается слева направо и справа налево после применения правил задачи.

Условия лабораторной работы:

- регистр игнорируется;
- обычные пробелы `" "` игнорируются;
- остальные символы сохраняются;
- пустой результат означает `Нет текста`.

```python
text = input("Введите текст: ")
cleaned = text.lower().replace(" ", "")

if cleaned == "":
    print("Нет текста")
elif cleaned == cleaned[::-1]:
    print("Палиндром")
else:
    print("Не палиндром")
```

### 10.1. Проверки

| Ввод | Очищенная строка | Результат |
|---|---|---|
| `А роза упала на лапу Азора` | `арозаупаланалапуазора` | Палиндром |
| `а    ` | `а` | Палиндром |
| Строка из пробелов | Пустая | Нет текста |
| `Python` | `python` | Не палиндром |
| `А!` | `а!` | Не палиндром |

### 10.2. Почему проверка пустоты идёт первой

Математически пустая строка равна своей перевёрнутой копии. Но условие работы отдельно требует вывести `Нет текста`. Поэтому специальный случай располагается до сравнения с обратной строкой.

Рассмотрим более короткий пример `"Топот"`. После `lower()` получаем `"топот"`; удалять пробелы не требуется. Обратный срез тоже даёт `"топот"`, значит сравнение истинно. Для `"топор"` обратная строка равна `"ропот"`, сравнение ложно.

Чтобы проверить своё понимание, сначала запишите рядом исходный текст, очищенный текст и его обратную запись. Затем определите, какая ветвь выполнится. Так легко отделить ошибку очистки от ошибки сравнения.

### 10.3. Вариант без обратного среза

Можно сравнить пары символов до середины:

```python
is_palindrome = True

for index in range(len(cleaned) // 2):
    if cleaned[index] != cleaned[-index - 1]:
        is_palindrome = False
        break
```

Цикл должен использовать длину **очищенной** строки. Если использовать длину исходной строки, индексы перестанут соответствовать данным после удаления пробелов.

## 11. Замена с предварительным подсчётом

Нужно заменить все двоеточия на дефисы и вывести количество замен.

```python
text = input("Введите текст: ")
replacement_count = text.count(":")
result = text.replace(":", "-")

print(f"Замен: {replacement_count}")
print(result)
```

Подсчёт выполняется в исходной строке до замены. После замены двоеточий уже не останется.

### 11.1. Примеры

| Исходная строка | Число двоеточий | Результат |
|---|---:|---|
| `a::b:` | 3 | `a--b-` |
| `abc` | 0 | `abc` |
| `:` | 1 | `-` |
| Пустая строка | 0 | Пустая строка |

### 11.2. replace заменяет все вхождения

```python
text = "a::b:"
print(text.replace(":", "-"))  # a--b-
```

Метод не останавливается после первой замены. Третий аргумент может ограничить количество замен, но в задании нужно заменить все вхождения.

## 12. Перебор символов

Строку можно перебирать напрямую:

```python
text = "Python"

for character in text:
    print(character)
```

Переменная `character` последовательно получает каждый символ.

### 12.1. Подсчёт без count

```python
text = input("Текст: ")
colon_count = 0

for character in text:
    if character == ":":
        colon_count += 1

print(colon_count)
```

Этот код показывает внутреннюю идею подсчёта. В обязательном задании можно использовать готовый `count()`.

### 12.2. Перебор по индексам

Если нужен индекс, можно использовать `range(len(text))`:

```python
text = "Python"

for index in range(len(text)):
    print(index, text[index])
```

Но при обычном чтении символов прямой цикл проще:

```python
for character in text:
    print(character)
```

Индекс нужен только тогда, когда он участвует в результате или требуется сравнить позиции.

## 13. Очистка и отбор слов

Индивидуальное задание работы №5 строится по единой схеме:

1. разбить строку через `split()`;
2. очистить края каждого слова;
3. привести слово к нижнему регистру;
4. пропустить пустой результат;
5. проверить условие варианта;
6. вывести подходящее слово и увеличить счётчик.

```python
text = input("Введите строку: ")
count = 0

for source_word in text.split():
    word = source_word.strip(".,!?;:").lower()

    if word == "":
        continue

    if word.startswith("а"):
        print(word)
        count += 1

if count == 0:
    print("Нет совпадений")

print(f"Количество: {count}")
```

Пример реализует вариант «начинается с `а`».

### 13.1. Зачем пропускать пустое слово

Для фрагмента `"!!!"`:

```python
word = "!!!".strip(".,!?;:")
print(word)  # пустая строка
```

После очистки символов не осталось. Обращение `word[0]` или `word[-1]` вызвало бы ошибку. Поэтому пустой результат обрабатывается до проверки начала и конца.

### 13.2. Повторы сохраняются

Если исходный текст содержит одно слово несколько раз, каждое вхождение обрабатывается отдельно:

```text
Анна, Анна! армия
```

Для условия «начинается с а» вывод будет:

```text
анна
анна
армия
```

Работа не требует удалять повторы.

### 13.3. Что меняется на каждой итерации

Для текста `"Анна, !!! армия!"` и условия «начинается с а»:

| Исходная часть | После очистки | Решение | Счётчик после шага |
|---|---|---|---:|
| `Анна,` | `анна` | Вывести слово | 1 |
| `!!!` | Пустая строка | Перейти к следующей итерации | 1 |
| `армия!` | `армия` | Вывести слово | 2 |

Счётчик создаётся перед циклом. Если поместить `count = 0` внутрь цикла, прежний результат будет сбрасываться при обработке каждого следующего слова.

## 14. Условия вариантов для слов

| Требование | Условие Python |
|---|---|
| Начинается с `а` | `word.startswith("а")` |
| Заканчивается на `я` | `word.endswith("я")` |
| Длина не меньше 5 | `len(word) >= 5` |
| Содержит букву `р` | `"р" in word` |
| Ровно одна буква `а` | `word.count("а") == 1` |
| Не содержит `а` | `"а" not in word` |
| Начинается и заканчивается одной буквой | `word[0] == word[-1]` |
| Длина от 3 до 5 | `3 <= len(word) <= 5` |
| Содержит `ра` | `"ра" in word` |
| Длина чётная | `len(word) % 2 == 0` |
| Начинается с гласной | `word[0] in "аеёиоуыэюя"` |

Проверки `word[0]` и `word[-1]` допустимы только после исключения пустого слова.

### 14.1. Контрольный текст

```text
Анна, армия! Я читаю. Книга, край, рама.
```

После очистки и изменения регистра:

```text
анна, армия, я, читаю, книга, край, рама
```

Для условия «содержит `р`» подходят `армия`, `край`, `рама`. Для условия «заканчивается на `й`» подходит только `край`.

## 15. От строки к списку

Результат `split()` является списком:

```python
text = "один два три"
words = text.split()

print(words)        # ['один', 'два', 'три']
print(type(words))  # <class 'list'>
```

Список хранит элементы в определённом порядке. В отличие от строки, список можно изменять.

Общие свойства строк и списков:

| Возможность | Строка | Список |
|---|---|---|
| `len(value)` | Да | Да |
| Индекс `value[i]` | Да | Да |
| Срез `value[a:b]` | Да | Да |
| Цикл `for` | Да | Да |
| Проверка `item in value` | Да | Да |
| Замена `value[i] = ...` | Нет | Да |
| Добавление элемента | Создаётся новая строка | `append()` меняет список |

Переход от строк к спискам естественен: ввод одной строкой разбивается на отдельные части, которые затем преобразуются и обрабатываются как набор данных.

<a id="section-16"></a>

## 16. Создание списка

Список записывается в квадратных скобках:

```python
numbers = [3, 7, 2, 7]
names = ["Анна", "Борис"]
empty = []
```

В одном списке технически могут находиться значения разных типов:

```python
mixed = [1, "текст", True]
```

Но в работе №6 используем списки целых чисел. Однородные данные проще сравнивать, сортировать и суммировать.

### 16.1. Ввод чисел одной строкой

`input().split()` даёт список строк. Каждую часть нужно преобразовать в число:

```python
parts = input("Целые числа через пробел: ").split()
numbers = []

for part in parts:
    numbers.append(int(part))

print(numbers)
```

Ввод:

```text
-2 0 5 3
```

Результат:

```text
[-2, 0, 5, 3]
```

### 16.2. Пустой ввод

Пустая строка после `split()` даёт пустой список:

```python
parts = "".split()
print(parts)  # []
```

Цикл не выполнится ни разу, поэтому `numbers` останется пустым.

### 16.3. Почему нужны и split, и int

Для ввода `"-2 0 5"` значения проходят три стадии:

```text
Одна строка:          "-2 0 5"
Список строк:        ['-2', '0', '5']
Список целых чисел:  [-2, 0, 5]
```

`split()` только определяет границы частей. Он не знает, обозначают части числа, фамилии или команды. Преобразование каждого элемента через `int()` — отдельное действие.

На каждой итерации состояние `numbers` меняется:

| Обработанная часть | Результат `int(part)` | Список после `append()` |
|---|---:|---|
| Ещё нет частей | — | `[]` |
| `"-2"` | -2 | `[-2]` |
| `"0"` | 0 | `[-2, 0]` |
| `"5"` | 5 | `[-2, 0, 5]` |

Выражение `numbers.append(int(part))` читается изнутри: сначала вычислить `int(part)`, затем передать полученное число методу `append()`.

## 17. Индексы, срезы и изменение списка

Индексы списка работают так же, как индексы строки:

```python
numbers = [10, 20, 30, 40]

print(numbers[0])   # 10
print(numbers[-1])  # 40
print(numbers[1:3]) # [20, 30]
```

Но элемент списка можно заменить:

```python
numbers = [10, 20, 30]
numbers[1] = 99

print(numbers)  # [10, 99, 30]
```

Это изменение того же объекта списка.

### 17.1. Срез создаёт новый список

Для плоского списка чисел срез можно использовать как копию:

```python
original = [1, 2, 3]
copy = original[:]
copy[0] = 99

print(original)  # [1, 2, 3]
print(copy)      # [99, 2, 3]
```

Позднее при работе со вложенными списками потребуется учитывать, что такая копия является поверхностной.

<a id="section-18"></a>

## 18. append, присваивание и pop

### 18.1. append добавляет новый элемент

```python
numbers = [1, 2]
numbers.append(3)

print(numbers)  # [1, 2, 3]
```

`append()` увеличивает длину списка на один.

### 18.2. Присваивание заменяет существующий элемент

```python
numbers = [1, 2]
numbers[0] = 10

print(numbers)  # [10, 2]
```

Длина не изменилась. Нельзя присвоить значение по индексу, которого ещё нет:

```text
numbers = []
numbers[0] = 10
```

Для пустого списка это `IndexError`. Новый элемент добавляется через `append()`.

### 18.3. pop удаляет и возвращает элемент

```python
numbers = [10, 20, 30]
removed = numbers.pop(1)

print(removed)  # 20
print(numbers)  # [10, 30]
```

Без аргумента удаляется последний элемент:

```python
last = numbers.pop()
```

У пустого списка `pop()` вызывает `IndexError`.

### 18.4. Что возвращают методы изменения списка

`append()` меняет список и возвращает `None`. Поэтому результат нужно читать из самого списка:

```python
items = ["старт"]
result = items.append("финиш")
print(items)   # ['старт', 'финиш']
print(result)  # None
```

Запись `items = items.append("финиш")` привела бы к тому, что имя `items` стало обозначать `None`. Метод `pop()` устроен иначе: он возвращает удалённый элемент. Возвращаемое значение каждого метода нужно изучать отдельно.

<a id="section-19"></a>

## 19. Обход списка

### 19.1. Обход по значениям

```python
numbers = [-2, 0, 5, 3]

for number in numbers:
    print(number)
```

Такой цикл подходит, когда нужен сам элемент, но не его позиция.

### 19.2. Обход по индексам

```python
for index in range(len(numbers)):
    print(index, numbers[index])
```

Эта запись полезна, если нужно изменить элементы исходного списка по позициям.

### 19.3. enumerate

`enumerate()` даёт пары «индекс, значение»:

```python
numbers = [3, 7, 2, 7]

for index, number in enumerate(numbers):
    print(index, number)
```

Результат:

```text
0 3
1 7
2 2
3 7
```

`enumerate()` используется в задании на все позиции максимума.

### 19.4. Переменная цикла и элемент списка

```python
numbers = [2, 4, 6]
for number in numbers:
    number = number + 1
print(numbers)  # [2, 4, 6]
```

Присваивание имени `number` не заменяет элемент списка. На очередном шаге это имя получает значение элемента, а затем связывается с другим числом. Сам список не изменяется.

Для намеренного изменения элементов по позициям используют индекс:

```python
numbers = [2, 4, 6]
for index in range(len(numbers)):
    numbers[index] = numbers[index] + 1
print(numbers)  # [3, 5, 7]
```

Если исходные данные должны сохраниться, строят отдельный список результата. Во время обычного обхода не стоит удалять элементы из той же последовательности: позиции сдвигаются, и часть элементов может быть пропущена.

## 20. Статистика списка

После создания списка доступны встроенные функции:

| Выражение | Результат |
|---|---|
| `len(numbers)` | Количество элементов |
| `sum(numbers)` | Сумма |
| `min(numbers)` | Минимум непустого списка |
| `max(numbers)` | Максимум непустого списка |

Полное решение обязательного задания:

```python
numbers = []

for part in input("Числа: ").split():
    numbers.append(int(part))

if len(numbers) == 0:
    print("Нет данных")
else:
    count = len(numbers)
    total = sum(numbers)
    minimum = min(numbers)
    maximum = max(numbers)
    average = total / count

    print(f"Количество: {count}")
    print(f"Сумма: {total}")
    print(f"Минимум: {minimum}")
    print(f"Максимум: {maximum}")
    print(f"Среднее: {average:.2f}")
```

### 20.1. Почему пустой список обрабатывается отдельно

```python
numbers = []
```

Для него:

- `len(numbers)` равно 0;
- `sum(numbers)` равно 0;
- `min(numbers)` вызывает `ValueError`;
- `max(numbers)` вызывает `ValueError`;
- деление на длину вызывает `ZeroDivisionError`.

Поэтому ветвь `Нет данных` должна выполняться до минимума, максимума и среднего.

### 20.2. Проверки статистики

| Ввод | Количество | Сумма | Минимум | Максимум | Среднее |
|---|---:|---:|---:|---:|---:|
| `-2 0 5 3` | 4 | 6 | -2 | 5 | 1.50 |
| `8` | 1 | 8 | 8 | 8 | 8.00 |
| Пустой ввод | Сообщение `Нет данных` | - | - | - | - |

## 21. Построение нового списка

Фильтрация и преобразование часто строят новый список, не меняя исходный.

### 21.1. Фильтрация

```python
numbers = [-2, 0, 5, 3]
positive = []

for number in numbers:
    if number > 0:
        positive.append(number)

print(positive)  # [5, 3]
```

В результат добавляются только подходящие элементы.

### 21.2. Преобразование каждого элемента

```python
numbers = [-2, 0, 5, -2]
absolute_numbers = []

for number in numbers:
    absolute_numbers.append(abs(number))

print(absolute_numbers)  # [2, 0, 5, 2]
```

Количество элементов сохраняется, но значения могут измениться.

### 21.3. Фильтрация и преобразование различаются

При фильтрации длина результата может уменьшиться. При преобразовании каждого элемента обычно сохраняется число элементов.

```text
Исходный список:      [-2, 0, 5, -2]
Фильтр положительных: [5]
Преобразование abs:   [2, 0, 5, 2]
```

## 22. Ссылка и независимая копия

Присваивание не создаёт копию списка:

```python
original = [1, 2, 3]
copy = original
copy[0] = 99

print(original)  # [99, 2, 3]
print(copy)      # [99, 2, 3]
```

Два имени ссылаются на один объект.

Для независимого плоского списка чисел используйте `copy()`:

```python
original = [1, 2, 3]
copy = original.copy()
copy[0] = 99

print(original)  # [1, 2, 3]
print(copy)      # [99, 2, 3]
```

### 22.1. Проверка тождества

Оператор `is` проверяет, являются ли две переменные ссылками на один объект:

```python
first = [1, 2]
second = first
third = first.copy()

print(first is second)  # True
print(first is third)   # False
print(first == third)   # True
```

`==` сравнивает содержимое, `is` - сам объект. Для обычного сравнения списков используется `==`.

### 22.2. Как представить связь имён

После `second = first` полезно мысленно представить две подписи к одной коробке. Через любую подпись мы получим одно и то же содержимое. Метод `append()` меняет содержимое этой общей коробки.

После `third = first.copy()` появляется другая внешняя коробка с теми же элементами. Для плоского списка чисел замена или добавление элемента в одной коробке не меняет другую. Эта аналогия помогает отличить копирование имени от создания отдельного контейнера.

`is` обычно не нужен для сравнения пользовательских данных. Два независимо созданных списка `[1, 2]` могут быть равны по содержимому, оставаясь разными объектами.

## 23. Независимое преобразование отрицательных чисел

Задание требует создать новый список, заменив отрицательные числа их модулями. Исходный список должен сохраниться.

```python
numbers = []

for part in input("Числа: ").split():
    numbers.append(int(part))

transformed = []

for number in numbers:
    if number < 0:
        transformed.append(abs(number))
    else:
        transformed.append(number)

print(f"Исходный: {numbers}")
print(f"Новый: {transformed}")
```

Для ввода `-2 0 5 -2`:

```text
Исходный: [-2, 0, 5, -2]
Новый: [2, 0, 5, 2]
```

### 23.1. Более короткое преобразование

Функция `abs()` не меняет неотрицательные числа, поэтому условие можно убрать:

```python
transformed = []

for number in numbers:
    transformed.append(abs(number))
```

Обе версии корректны. Первая явно показывает выбор, вторая точнее использует свойство `abs()`.

### 23.2. Изменение исходного списка не соответствует заданию

```python
for index in range(len(numbers)):
    numbers[index] = abs(numbers[index])
```

Этот код преобразует значения на месте. Если требуется сохранить исходный список, такой вариант не подходит без предварительной независимой копии.

## 24. Все позиции максимума

Для списка `3 7 2 7` максимум равен 7 и встречается по индексам 1 и 3.

Алгоритм состоит из двух этапов:

1. проверить, что список не пуст, и найти максимум;
2. пройти список с индексами и сохранить все совпадения.

```python
numbers = []

for part in input("Числа: ").split():
    numbers.append(int(part))

if len(numbers) == 0:
    print("Нет данных")
else:
    maximum = max(numbers)
    positions = []

    for index, number in enumerate(numbers):
        if number == maximum:
            positions.append(index)

    print(f"Максимум: {maximum}")
    print(f"Индексы: {positions}")
```

### 24.1. Почему нужен список позиций

Одной переменной недостаточно: каждое новое совпадение перезаписало бы старый индекс. `positions.append(index)` сохраняет все найденные позиции.

### 24.2. Проверки

| Ввод | Максимум | Индексы |
|---|---:|---|
| `3 7 2 7` | 7 | `[1, 3]` |
| `7 7` | 7 | `[0, 1]` |
| `-3 -1 -2` | -1 | `[1]` |
| `5` | 5 | `[0]` |
| Пустой ввод | Нет данных | - |

Индексы начинаются с нуля и добавляются при движении слева направо, поэтому результат уже расположен по возрастанию.

## 25. sorted и sort

`sorted()` возвращает новый отсортированный список:

```python
numbers = [3, 1, 2]
ordered = sorted(numbers)

print(numbers)  # [3, 1, 2]
print(ordered)  # [1, 2, 3]
```

Метод `sort()` изменяет существующий список и возвращает `None`:

```python
numbers = [3, 1, 2]
result = numbers.sort()

print(numbers)  # [1, 2, 3]
print(result)   # None
```

### 25.1. Типичная ошибка

```python
numbers = [3, 1, 2]
numbers = numbers.sort()
print(numbers)  # None
```

Сначала метод сортирует исходный список, затем возвращаемое значение `None` присваивается имени `numbers`. Ссылка на список теряется.

### 25.2. Сортированная копия результата

В индивидуальном задании нужно сохранить выборку в исходном порядке и отдельно получить сортированную копию:

```python
selected = [6, -8, 0, 6]
ordered = sorted(selected)

print(selected)  # [6, -8, 0, 6]
print(ordered)   # [-8, 0, 6, 6]
```

Повторы сохраняются.

## 26. Фильтрация списка по условию

Общая схема индивидуального задания работы №6:

numbers = []

for part in input("Числа: ").split():

selected = []

for number in numbers:

## 27. Условия вариантов для чисел

| Требование | Условие Python |
|---|---|
| Чётные | `number % 2 == 0` |
| Отрицательные | `number < 0` |
| Модуль больше 5 | `abs(number) > 5` |
| Нечётные | `number % 2 != 0` |
| Положительные | `number > 0` |
| Кратные 3 | `number % 3 == 0` |
| Не кратные 3 | `number % 3 != 0` |
| От 10 до 20 включительно | `10 <= number <= 20` |
| Ненулевые | `number != 0` |
| Не меньше 10 | `number >= 10` |
| Модуль не больше 3 | `abs(number) <= 3` |
| Положительные чётные | `number > 0 and number % 2 == 0` |
| Отрицательные нечётные | `number < 0 and number % 2 != 0` |
| Кратные 5 | `number % 5 == 0` |
| Оканчиваются на 2 в записи модуля | `abs(number) % 10 == 2` |

Эти условия уже встречались в работе с потоками. Теперь подходящие значения сохраняются в списке, поэтому их можно повторно использовать, сортировать и выводить целиком.

### 27.1. Ноль

Ноль:

- является чётным;
- кратен 3 и 5;
- не является положительным;
- не является отрицательным;
- имеет модуль 0.

При проверке вариантов нужно применять математическое условие, а не бытовое представление о числе.

## 28. Списковые включения

Списковое включение - краткая запись построения списка.

Преобразование через цикл:

```python
absolute_numbers = []

for number in numbers:
    absolute_numbers.append(abs(number))
```

Эквивалентное включение:

```python
absolute_numbers = [abs(number) for number in numbers]
```

Фильтрация через цикл:

```python
positive = []

for number in numbers:
    if number > 0:
        positive.append(number)
```

Эквивалентное включение:

```python
positive = [number for number in numbers if number > 0]
```

Порядок чтения включения отличается от порядка его записи. Сначала найдите часть `for number in numbers`: она задаёт перебор. Затем найдите необязательную часть `if`: она пропускает неподходящие значения. Выражение слева от `for` определяет, что добавить в новый список.

Например, для `numbers = [-1, 2, 3]` выражение `[number * 10 for number in numbers if number > 0]` сначала пропустит -1, затем добавит 20 и 30. Оно объединяет отбор и преобразование.

Сначала нужно уверенно понимать вариант с обычным циклом. Включение не меняет алгоритм, а только сокращает запись.

### 28.1. Преобразование и условие вместе

```python
squares_of_positive = [number ** 2 for number in numbers if number > 0]
```

Сначала перебирается `numbers`, затем проверяется условие, после чего в результат добавляется квадрат подходящего числа.

Не объединяйте слишком много правил в одной строке. Понятный цикл часто лучше сложного включения.

## 29. Типичные ошибки

### 29.1. Строки

| Ошибка | Последствие | Проверка |

| Результат `lower()` не сохранён | Регистр не изменился | Вывести исходную и новую строки |

| Не пропущено пустое очищенное слово | Ошибка первого или последнего символа | Проверить строку `!!!` |

### 29.2. Списки

| Ошибка | Последствие | Проверка |
|---|---|---|
| `numbers[0] = value` для пустого списка | `IndexError` | Добавлять через `append()` |
| `copy = original` вместо копии | Меняются оба имени | Изменить один элемент копии |

| Фильтрация через множество | Теряются порядок и повторы | Строить список через `append()` |

## 32. Вопросы с разбором

### 32.1. Что вернёт `"Python"[1:4]`?

Строку `"yth"`. Индекс 1 входит, индекс 4 не входит.

### 32.2. Что означает индекс `-1`?

Последний элемент непустой последовательности. Для строки `"Python"` это `"n"`.

### 32.3. Почему `text[0]` опасен после очистки?

Очистка может удалить все символы. Для пустой строки индекс 0 не существует. Сначала нужно проверить `if text:`.

### 32.4. Изменит ли `text.lower()` переменную text?

Нет. Метод вернёт новую строку. Результат нужно присвоить или сразу использовать.

### 32.5. Чем `split()` без аргумента отличается от `split(" ")`?

Вариант без аргумента объединяет последовательности пробельных символов и не создаёт пустых частей по краям. Явный разделитель обрабатывается буквально и может дать пустые элементы.

### 32.6. Почему `" ".join(text.split())` нормализует пробелы?

`split()` выделяет непустые слова, а `join()` вставляет между ними ровно один пробел.

### 32.7. Является ли строка из пробелов палиндромом в работе №5?

По условию нет текста. После удаления обычных пробелов строка пуста, поэтому нужно вывести `Нет текста` до проверки палиндрома.

### 32.8. Почему `А!` не палиндром?

Правила игнорируют регистр и пробелы, но сохраняют пунктуацию. Очищенная строка `а!` не равна `!а`.

### 32.9. Когда считать двоеточия: до или после replace?

До замены. После `replace(":", "-")` двоеточий уже нет.

### 32.10. Что получится из пустого ввода чисел?

`input().split()` вернёт пустой список, цикл добавления не выполнится.

### 32.11. Чем append отличается от присваивания по индексу?

`append()` создаёт новый элемент в конце. Присваивание меняет уже существующую позицию.

### 32.12. Что произойдёт после `copy = original`?

Оба имени будут ссылаться на один список. Изменение через любое имя будет видно через другое.

### 32.13. Что возвращает sort()?

`None`. Метод изменяет список на месте. Для нового списка используется `sorted()`.

### 32.14. Можно ли вызвать sum для пустого списка?

Да, результат равен 0. Но `min()` и `max()` для пустого списка недопустимы, а среднее потребует деления на ноль.

### 32.15. Почему позиции максимума ищутся после max?

Сначала нужно знать значение, с которым сравнивать каждый элемент. Затем полный обход собирает все совпадающие индексы.

### 32.16. Сохраняет ли sorted повторы?

Да. Сортировка меняет порядок, но не удаляет элементы.

### 32.17. Почему set не подходит для индивидуального задания?

Задание требует сохранить повторы и исходный порядок. Множество предназначено для уникальных значений и не решает эту задачу.

### 32.18. Чем фильтрация отличается от преобразования?

Фильтрация выбирает часть элементов. Преобразование создаёт новое значение для каждого обрабатываемого элемента.

### 32.19. Что даст enumerate для списка `[7, 7]`?

Пары `(0, 7)` и `(1, 7)`. Поэтому все позиции максимума равны `[0, 1]`.

### 32.20. Зачем отдельно проверять единичный элемент?

Он показывает правильность начальных значений, среднего, минимума, максимума и индекса 0 без перехода между элементами.

## 33. Краткий словарь

| Термин | Значение |
|---|---|
| Строка | Неизменяемая последовательность символов |
| Символ | Элемент строки длиной один |
| Индекс | Номер позиции, начинающийся с нуля |
| Отрицательный индекс | Позиция, отсчитываемая с конца |
| Срез | Часть последовательности с исключённой правой границей |
| Неизменяемость | Невозможность заменить часть существующего объекта |
| Метод | Операция, вызываемая через точку у объекта |
| Нормализация | Приведение разных форм записи к заданной форме |
| Подстрока | Последовательность символов внутри строки |
| Палиндром | Текст, совпадающий со своей обратной записью по заданным правилам |
| `split()` | Разбиение строки на список частей |
| `join()` | Соединение строк через выбранный разделитель |
| Список | Изменяемая упорядоченная последовательность элементов |
| Пустой список | Список без элементов, записываемый `[]` |
| `append()` | Добавление одного элемента в конец списка |
| `pop()` | Удаление и возврат элемента списка |
| `enumerate()` | Получение пар «индекс, значение» при обходе |
| Ссылка | Связь имени с объектом |
| Копия | Отдельный объект с тем же содержимым |
| Поверхностная копия | Новый внешний список с теми же вложенными объектами |
| Фильтрация | Построение результата только из подходящих элементов |
| Преобразование | Получение нового значения из каждого элемента |
| `sorted()` | Создание нового отсортированного списка |
| `sort()` | Сортировка существующего списка на месте |
| Списковое включение | Краткая запись построения списка из цикла и условия |

Основная идея лекции: строка и список являются последовательностями, поэтому для них работают длина, индексы, срезы и цикл. Строковые операции создают новые значения, а список можно менять. Перед обработкой текста задают правила нормализации, перед обработкой списка решают, нужно ли сохранять исходные данные. Пустой ввод проверяют до операций, которым нужен хотя бы один элемент.
